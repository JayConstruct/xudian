# 拾光教务导入

当前独立模块 `app.import.shiguang` 为 **1.4.0**，需要宿主 API **1.9.0** 及课表 **1.6.1 或更新版本**。内置学校脚本快照，当前学校搜索覆盖 243 所学校、265 个入口，另有正方、青果、URP、超星 4 个通用系统。独立正方模块已移除，正方导入从拾光内进入。

## 选择入口

| 入口 | 用途 |
| --- | --- |
| 按学校导入 | 搜索校名/缩写，进入详情后选择本科、研究生、校内或 WebVPN 入口 |
| 通用系统导入 | 搜不到学校时尝试正方、青果、URP、超星通用脚本 |
| 粘贴学校脚本 | 使用本地已有拾光适配脚本，脚本仅在当前运行会话保留 |
| JSON 文件导入 | 使用同一转换、配置和预览流程；桌面也可使用 |
| 关于与致谢 | 上游、序点源码、贡献者及完整 MIT 许可，地址可复制 |

搜索列表只显示校名、分类或入口数量；使用说明、维护者、原始源码及登录网址在详情中查看。App 顶栏随当前页变化，左上角箭头和系统返回处理内部上一层，首页才退出模块；返回保留搜索、网址和未保存草稿。

## 导入流程

1. 选择学校/脚本，填写教务网址，打开 Android 教务浏览器并自行登录。
2. 进入个人课表查询，选择学年学期并查询，再点击“执行采集”。
3. 选择新建或已有课表，确认名称、来源、第一周周一、周数、时区及起始星期。
4. 查看转换摘要及实际变更，处理冲突，再交给课表确认和宿主审核。取消采集、配置或预览不写入课程。

来源标识使用稳定的“学校/账号别名/学年学期”，重复导入保持一致，不含密码。配置和草稿按来源隔离；切换学校或脚本清除旧来源草稿，取消新采集可保留此前草稿并明确提示。

默认正方通用脚本要求页面支持对应 jQuery 表格/列表选择器，不适用于所有正方版本。它通常只返回课程；新建采用 12 节模板，第一周日期由用户填写，合并优先沿用已有作息。学校脚本保存的学期配置与作息也可采集，仍需按实际学校确认。

## 转换与兼容范围

课程支持 `name/day/startSection/endSection/weeks/teacher/position`、明确周次/单双周展开、多段安排、颜色、备注和学分。重复周次片段合并；优先使用显式 `courseSourceId` / `sourceId`。上游随机 ID 或课程代码不当作稳定安排 ID，缺失时按课程、星期、节次、教师和地点建立键；除周次外的字段变化可能形成新安排，预览会提示。

桥接支持 `shiguangBridge` / `shiguangBridgePromise` 和旧 `AndroidBridge` 别名，包括提示、输入、单选、课程、学期配置、作息及完成通知。保存调用只暂存，结束通知后一次返回；空课程或保存失败不报告成功。浏览器关闭、导航、重新执行及停用使旧结果失效，不返回 Cookie 或登录凭据。

导入默认视为局部结果，明确确认全量后才允许删除来源中缺失项，已有课表再做三方冲突处理。兼容模块只能准备计划，不能直接提交课表写集；配置变化或参与者实例变化需要重新准备。

支持数字字符串节次/周次/星期、整分秒格式时间和按节次排序的作息。自定义时刻必须准确对应已有节次，不近似取整；夏冬季组合作息仍需进一步适配。周日起始会调整源周次以保持日期；落在课表第一周周一之前的课程无法表示时整份拒绝，避免静默丢课。

内置浏览器仅实现 Android。页面加载失败保留 DNS、连接、HTTP 或证书提示，并禁用采集；重新成功加载才恢复。先检查设备网络，再核对校园网/学校 VPN 要求。输入网址或缩写时需完成输入法组合文本提交。
