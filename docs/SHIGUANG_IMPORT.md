# 拾光教务导入

源码版本和依赖兼容范围以 [模块清单](../packages/modules/app.import.shiguang/module.json) 为准。源码与本地候选包不代表商店或设备已更新。内置学校脚本快照，当前学校搜索覆盖 243 所学校、265 个入口，另有正方、青果、URP、超星 4 个通用系统。独立正方模块已移除，正方导入从拾光内进入。

## 选择入口

| 入口 | 用途 |
| --- | --- |
| 按学校导入 | 搜索校名/缩写，进入详情后选择本科、研究生、校内或 WebVPN 入口 |
| 通用系统导入 | 搜不到学校时尝试正方、青果、URP、超星通用脚本 |
| 粘贴学校脚本 | 使用本地已有拾光适配脚本，脚本仅在当前运行会话保留 |
| JSON 文件导入 | 使用同一转换、配置和预览流程；桌面也可使用 |
| 关于与致谢 | 上游、序点源码、贡献者及完整 MIT 许可，地址可复制 |

搜索列表只显示校名、分类或入口数量；使用说明、维护者、原始源码及登录网址在详情中查看。App 顶栏随当前页变化，左上角箭头和系统返回处理内部上一层，首页才退出模块；返回保留搜索、网址和未保存草稿。

## 导入流程

1. 选择学校/脚本，填写教务网址，打开 Android 教务浏览器并自行登录。
2. 进入个人课表查询，选择学年学期并查询，再点击“执行采集”。
3. 选择新建或已有课表，确认名称、来源、第一周周一、周数及起始星期；时区自动确定。
4. 查看转换摘要及实际变更，处理冲突，再交给课表确认和宿主审核。取消采集、配置或预览不写入课程。

来源标识默认留空，按学校或网址及第一周日期生成稳定值；JSON 与学校模块分别生成来源标识。多账号或接续旧导入时可填写固定标识，自行区分学校、账号和学期，重复导入保持一致且不含密码。配置和草稿按来源隔离；切换学校或脚本清除旧来源草稿，取消新采集可保留此前草稿并明确提示。

导入已有课表保留目标课表时区；新建时优先保留来源明确的 `config.timezone` 或 `payload.timezone`，没有来源时区才采用设备系统时区。无法获取时明确显示 `Asia/Shanghai` 回退提示，之后可在课表学期信息的高级设置中修改。纯转换函数保持同步、无系统读取，调用方须显式提供时区或由来源携带；不再隐式假定上海。完整 JSON 课表备份通过课表自身入口导入时，保留备份时区。

默认正方通用脚本要求页面支持对应 jQuery 表格/列表选择器，不适用于所有正方版本。它通常只返回课程；新建采用 12 节模板，第一周日期由用户填写，合并优先沿用已有作息。学校脚本保存的学期配置与作息也可采集，仍需按实际学校确认。

## 表单、主题与草稿

没有课表时跳过导入目标选择；已有课表时可新建、合并或替换来源。确认学期后自动进入实际变更预览。

- 教务网址使用明文网址输入。省略协议默认补全 `https://`，保留明确输入的 `http://`。学校入口与自定义入口各自记住上次网址，并记录最近使用的网址。校验拒绝非 HTTP(S) 协议和包含账号密码的地址。
- 第一教学周使用日期选择器。选择该周任意一天，界面与转换逻辑都换算为该周周一。来源提供的学期日期优先；已有课表与上次配置可用于预填。无法判断学期起始时要求选择日期，不猜测当前学期。
- 学期配置和粘贴脚本使用 APP 页面形式的表单，保留顶部关闭入口和底部主操作。脚本中的确认、输入和单项选择通过浏览器会话传输为原生弹窗；单项选择直接点击选项。旧宿主仍可使用浏览器提示框兼容路径。
- 学校登录与适配脚本采集的原生工具栏、输入、提示框与系统栏接收 App 当前实际主题；手动浅深色及跟随系统均适用，学校网页本身的配色保留。Android 15 及之后的透明系统栏由对应主题窗口背景承接，图标按主题设置，系统栏避让保留。工具按钮至少 48dp，按系统字号扩展，工具区在空间不足时横向滚动；原生控件使用与 App 对应的连续角形状、14 控件／24 浮层半径和对齐的 20 页面边距。
- 全局 Material 页面使用淡入与短距离滑动；iOS 保留原生返回手势。拾光内部页面切换同样播放过渡。开启减少动态效果时关闭这些视觉动画。

网址与上次表单配置使用模块隔离的 UI preferences；课程与导入来源记录继续由课表模块的审核流程管理。脚本正文和课程草稿只保存在当前页面会话。

## 转换与兼容范围

课程支持 `name/day/startSection/endSection/weeks/teacher/position`、明确周次/单双周展开、多段安排、颜色、备注和学分。重复周次片段合并；优先使用显式 `courseSourceId` / `sourceId`。上游随机 ID 或课程代码不当作稳定安排 ID，缺失时按课程、星期、节次、教师和地点建立键；除周次外的字段变化可能形成新安排，预览会提示。

桥接支持 `shiguangBridge` / `shiguangBridgePromise` 和旧 `AndroidBridge` 别名，包括提示、输入、单选、课程、学期配置、作息及完成通知。保存调用只暂存，结束通知后一次返回；空课程或保存失败不报告成功。浏览器关闭、导航、重新执行及停用使旧结果失效，不返回 Cookie 或登录凭据。

导入默认视为局部结果，明确确认全量后才允许删除来源中缺失项，已有课表再做三方冲突处理。兼容模块只能准备计划，不能直接提交课表写集；配置变化或参与者实例变化需要重新准备。

支持数字字符串节次/周次/星期、整分秒格式时间和按节次排序的作息。自定义时刻必须准确对应已有节次，不近似取整；夏冬季组合作息仍需进一步适配。周日起始会调整源周次以保持日期；落在课表第一周周一之前的课程无法表示时整份拒绝，避免静默丢课。

内置浏览器仅实现 Android。页面加载失败保留 DNS、连接、HTTP 或证书提示，并禁用采集；重新成功加载才恢复。先检查设备网络，再核对校园网/学校 VPN 要求。输入网址或缩写时需完成输入法组合文本提交。
