# 序点界面设计系统

当前公共 UI 契约、自定义界面包、模块选择、模拟预览与恢复见 [公共 UI 与界面包](UI_COMPONENTS.md)。以下旧架构章节保留历史设计说明，当前生产协议以该文档和 v3 宿主文档为准。

状态核对日期：2026-10-02。当前界面使用 v2 模块架构；实现进度见 [项目首页](../README.md)。

## 方向

界面以任务内容为中心。画布使用低饱和中性色，控制层使用轻微透明和柔和阴影。导航、任务行与弹窗通过间距和 Surface 亮度建立层级，避免密集边框。浅色与深色模式共用组件和布局规则。

## 当前实现

- `client/lib/app/design_system.dart` 定义画布、品牌色、圆角、浮层与任务信息行。
- `client/lib/app/app.dart` 统一 Material 3 的颜色、输入、卡片、弹窗、菜单和按钮主题。
- `client/lib/app/app_shell.dart` 按窗口宽度提供侧栏/底栏和轻量页面标题：小于 820 使用底栏，至少 820 使用侧栏；AI 在至少 1100 的宽度显示侧面板，其他宽度显示 Sheet。
- 默认导航为“今天、收件箱、项目、模块”，AI 默认使用顶部入口。主导航直显上限只计普通入口，不计“更多”；窄屏默认 4 个，按可用空间和文字缩放动态减少，宽屏默认不限制。任务基础编辑已支持标题、优先级与计划/截止日期：小于 820 使用底部面板，至少 820 使用右侧模态面板；非模态列表/详情分栏、看板和完整编辑器尚未实现。
- 移动底栏由 `client/lib/app/mobile_bottom_dock.dart` 渲染：快速输入与导航共用玻璃面板，半透明渐变、18px 背景模糊、细边缘高光和柔和阴影；面板悬浮在内容上方，列表通过 `WorkspaceContentInsets` 留出末项滚动空间。
- 选中项使用实心图标、略粗文字和滑动胶囊，切换约 220ms；胶囊通过绘制位移过渡，不逐帧修改 Stack 布局。按压轻微缩小并提供水波纹，导航切换触发轻触反馈。适配浅色/深色、大字和高对比模式，系统减少动画时关闭位移/缩放过渡；高对比模式使用不透明底栏并跳过背景模糊。
- 页面内容、玻璃底栏、底栏交互内容和胶囊各自设置重绘边界，隔离列表、按压、水波纹及指示器的重绘。正常模式保留既有模糊强度、阴影和连续圆角。
- 键盘弹出时隐藏导航，保留贴近键盘的快速输入；空文本时提交按钮禁用，提示文字显示当前添加页面。底栏高度变化用平滑动画处理。
- 项目详情底部提供专属任务输入，自动关联当前项目；与主输入共用 `QuickTaskInput`。提交中禁用重复提交，错误使用 SnackBar，保留失败草稿与提交期间的新草稿。
- 内置任务视图和声明式任务视图都使用 `TaskObjectTile`，由客户端决定字体、颜色、状态和 Hover 反馈。

## 页面层级与设置

- **画布**：浅色使用冷灰、深色使用低亮度灰蓝，作为页面底色。
- **标题与分组**：主标题直接置于画布上；数量、分组名和说明使用较小的次要文字，项目与模块页的操作使用柔和填充按钮，避免重复大标题。
- **内容**：任务、项目及设置分组使用实色 Surface 与一致的边距；完成任务降低背景和文字的视觉权重。任务列表显示待办/完成数量，空状态提供图标与下一步说明，留出底栏遮挡空间。桌面内容宽度限制为 1040，设置详情为 760。
- **悬浮操作**：玻璃、模糊与阴影集中用于底部输入/导航和桌面辅助面板。对话框与 Sheet 承载临时选择或次级操作。
- 设置入口位于移动端标题右侧、桌面侧栏底部，打开独立页面并保留工作台与输入草稿。
- 设置包括跟随系统/浅色/深色主题、减少动画、导航触感、入口与页面布局、界面标注、AI 连接、模块管理及关于/本机数据说明。外观与交互偏好保存到 `AppSettings` 的 `ui.preferences`，布局另存 `ui.layout`，无需数据库结构迁移；保存成功后应用，系统减少动画偏好始终生效。
- AI 地址/模型/API Key 在独立连接页面显式保存，设置页与 AI 模块生成页面共用此入口；远程地址须使用 HTTPS，本机回环地址可使用 HTTP，空密钥保存会删除旧密钥。AI 模块生成页面保留需求、生成操作与折叠的高级 JSON 编辑器，说明生成时发送功能描述和已安装模块标识/版本，确认变更后才安装或更新。按钮使用“生成并查看变更”，不暗示提供模块界面的实时预览。
- 模块管理分为“内置功能”和“扩展模块”：内置功能注明启用状态，不在列表中展示原生/声明式等实现术语。项目、AI、今天/收件箱提供开关，模块管理显示锁定标识并保持可用。关闭 AI 同步隐藏顶部入口、设置中的连接入口及桌面面板；关闭当前工作台视图时回退，其他导航变化保留当前页面身份，重新启用恢复目录顺序。所有视图关闭后仍可通过模块管理恢复。开关状态保存在 `modules.builtin.<id>`，关闭保留业务数据和连接配置。
- 模块权限与资源类别使用中文含义并保留技术标识；模板入口使用“从模板创建任务”，说明可能同时创建项目。版本操作使用“恢复配置”，明确不会撤销已创建任务或已执行的自动化；彻底删除提示说明会清理模块记录、版本、自定义字段和规则运行记录，但保留任务和项目。今天空状态需对应今天待办与逾期任务的实际筛选范围。

## 连续圆角

矩形控件与面板统一使用 Flutter 原生连续圆角（`RoundedSuperellipseBorder`），直线与角部曲线平滑衔接。半径由 `AppDesign` 集中管理：

| 组件 | 半径 |
| --- | --- |
| 标签与筛选 Chip | 12 |
| 输入框、按钮、桌面侧栏选项 | 14 |
| 任务卡片、项目卡片 | 16 |
| 导航选中背景、弹出菜单 | 20 |
| 辅助浮层、对话框 | 24 |
| 底部玻璃面板、Sheet 顶角 | 28 |

背景、边框和阴影使用相同的 `ShapeDecoration` / Material 形状；玻璃模糊用同半径的 `ClipRSuperellipse` 裁剪，水波纹跟随对应形状。输入框使用 `ShapedInputBorder` 保留浮动标签与焦点、错误状态。Sheet 仅顶部使用圆角；圆形图标按钮和开关保持适合其交互的形状。

## 模块与 AI 页面约束

内置“UI 示例”由模块管理的内置卡片打开，默认不增加主导航；“UI 示例贡献”提供跨模块页签、纵向内容与失效演示，两者均为可开关原生模块。示例复用任务卡片、内容 Surface 和状态组件，展示表单、弹窗、公开／私有槽位及局部位置；演示状态仅保存在本次运行中，可手动重置。模块只申请 `ui.register`，不读取或写入真实任务、项目或字段。原生示例不作为声明式运行时控件支持范围的声明。

模块只描述资源与语义，例如页面标题、图标名、视图、过滤条件、字段和页面槽位，不提供字体、颜色、圆角、阴影、尺寸或导航样式。版本 1 保持全页导航且非空 `layouts` 被拒绝；版本 2 支持 `view / container`、公开／私有页面槽位与 `layouts` 贡献，只有显式入口对象（包括 `entry: {}`）才注册入口，省略／`null`／`false` 不注册。v2 需声明 `ui.composition`、`ui.registry` 和 `ui.register`。解析器严格拒绝未知组合字段，引用、上下文、权限和挂载兼容性仍由运行时检查；JSON Schema 不代替这些检查。任务视图继续使用统一任务列表组件。

未来增加分组、看板、统计块或详情区块时，应先在客户端实现并纳入组件注册表，再扩展声明式 Schema 与语义校验。模块只选择受支持的组件及低饱和辅助色语义，不提交任意样式值或可执行 UI 代码。新增组件须同时适配移动、桌面、浅色和深色模式。

AI 提案继续经过解析、权限校验、差异预览和用户确认。视觉风格由客户端渲染器控制，提示词只辅助模型生成有效配置，不能作为风格约束的唯一防线。

## 入口编排、嵌套与标注

- 底栏仍属核心壳层，开放入口编排而非卸载；设置、模块管理和布局恢复保留可达途径。用户在设置中分别编排小于 820px 的窄屏及至少 820px 的宽屏配置，调整位置、顺序和隐藏状态，不使用自由画布。保存前为草稿，恢复默认只修改当前编辑范围的草稿。
- 入口位置与打开方式分离，每个入口只有一个挂载位置；同一页面可由不同入口引用。页面槽位支持 `entries` 按钮区、`tabs` 页签区和 `sections` 纵向内容，私有槽位只接受本模块，公开槽位接受兼容的跨模块贡献。数据操作仍执行贡献模块自己的权限，公开槽位不授予宿主权限。
- 上下文不满足、宿主不可用或槽位变更时展示失效原因，并保留挂载；用户可暂时保持不变或进入布局页处理。不要把失效内容显示为有效数据。页面仅在 `retainPosition: true` 时保留局部页签／滚动位置，只限本次运行，重启清空。
- 嵌套达到 8 层提醒用户调整，不设深度硬上限；循环内容嵌套停止对应分支并提供原因，不能使其他区域一起失效。
- 界面标注默认关闭，覆盖已登记的可见关键 UI，不为每个装饰元素标注。覆盖层不改变业务布局，支持暂时隐藏和退出；`U` 编号只在当前会话有意义，稳定 UI ID 用于准确描述组件。复制仅包含静态名称、模块、路径、槽位和作用，不读取正文、输入值、业务对象 ID 或密钥，不自动截图或上传。

协议、默认值、导入区别和模块 source 示例见 [UI 组合](UI_COMPOSITION.md)。
