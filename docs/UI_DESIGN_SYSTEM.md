# 界面设计系统

核对日期：2026-10-14。当前生产界面由 Flutter 宿主及 v3 模块贡献组成；组件与 UI 包契约见 [公共 UI 与界面包](UI_COMPONENTS.md)，模块协议见 [JavaScript SDK](MODULE_SDK.md)。

## 规则来源与修改顺序

本文是当前宿主设计规则的入口；[柔和极简界面](design/SOFT_MINIMAL_UI.md)记录风格意图和页面场景。当前实现的数值与行为以公共组件为依据；“间距与文字层级”“页面状态与操作反馈”中的选择规则是新建或修改页面时的验收要求，不表示所有既有页面已自动统一。具体偏差应记录后逐项修复，不从历史参考图或归档文档重新推导。

| 规则 | 维护位置 | 复用方式 |
| --- | --- | --- |
| 默认颜色、连续圆角、按钮与弹窗主题 | `client/lib/core/ui/ui_design.dart` 中的 `AppDesign` | 使用当前 `Theme`；特定形状复用 `AppDesign.smoothShape` |
| 工作区标题、标题测高 | `client/lib/core/ui/workspace_typography.dart`、`workspace_header.dart` | 复用 `WorkspaceTypography` 和工作区顶栏 |
| 共用动效时长与减少动画 | `client/lib/core/ui/ui_motion.dart` 中的 `AppMotion` | 复用对应语义的时长和 `AppMotion.duration` |
| 卡片、详情页、分区标题 | `client/lib/core/ui/ui_surfaces.dart` | 复用 `ContentSurface`、`DetailPage`、`SectionHeading` |
| 错误、按钮、短暂反馈 | `client/lib/core/ui/ui_feedback.dart`、`ui_toast.dart` | 复用 `AppErrorState`、`appUiButtonStyle`、`AppToast` |
| 界面包覆盖和必达槽位 | [公共 UI 与界面包](UI_COMPONENTS.md)、`ui_component.dart` | 原生使用 `NativeUi`，模块使用既有公共组件引用 |

`client/lib/app/design_system.dart` 是兼容导出；不要在那里新增第二套主题。界面包的 `radius`、`spacing` 和 `fontScale` 是现有覆盖契约，作用范围由 `applyUiPackTheme` 和 recipe 决定；`spacing` 目前调整原生列表条目留白，不代表全页面缩放。默认规则变更先更新公共实现及受影响场景，再同步本文和风格说明。当前冲突修正与验证入口见 [规则核对记录](design/UI_RULES_AUDIT.md)。

## 共用视觉

- 使用低饱和画布、实色内容 Surface、清晰间距和次要文字区分层级；浮层、底栏集中使用透明、模糊和柔和阴影。
- 浅色与深色共用布局与组件语义。颜色、形状和默认控件主题由 `AppDesign` 集中维护，`app.dart` 应用主题及用户界面包。
- 公共组件覆盖卡片、表单、列表、设置和导航；UI 包可替换受支持的组件配方，模块也可选择专属风格，不能移除宿主保留的菜单和恢复入口。
- 组件变更应一起检查浅色、深色、窄屏、宽屏和大字体；业务信息不依赖颜色或图标单独表达。

## 连续圆角与选择框

普通矩形表面、按钮、输入和菜单使用 `RoundedSuperellipseBorder`；背景、边框、阴影、裁剪和水波纹跟随同一形状。圆形图标按钮、开关、筛选 Chip 与导航胶囊按交互语义保留圆形或胶囊形。

| 组件 | 默认半径 |
| --- | --- |
| 紧凑矩形形状（`compactRadius`） | 12 |
| 筛选 Chip | 胶囊形（`StadiumBorder`） |
| 输入框、按钮、侧栏选项 | 14 |
| 内容卡片 | 20 |
| 导航选中背景、弹出菜单 | 20 |
| Toast | 20 |
| 对话框与辅助浮层 | 24 |
| 底部玻璃面板、Sheet 顶角 | 28 |

选择框的弹出面板、选项和选中状态使用圆角与一致间距，长文本可换行或省略并保持可识别；选项数量较多时可滚动。圆形图标按钮和开关保留适合交互的形状。

2026-10-15：商店搜索、筛选与离线提示、调用方式弹窗和脚本折叠区已改为复用公共输入主题及连续形状；源码／表单关闭／关于页图标复用 `UiIcon`。学校采集的原生宿主区域接收 Flutter 当前实际主题颜色，提示框与系统栏保持对应风格；网页本身不强制改变配色。Android 原生曲线按连续角语义绘制，不宣称与 Flutter 曲线逐像素相同。

## 间距与文字层级

以下是新建与修改页面时的默认选择；目前没有把该表实现为全局间距 token，也没有对所有页面批量替换。特殊网格和密集数据可按可用空间调整，已有组件内部几何由组件持有。

| 场景 | 默认逻辑尺寸 | 选择规则 |
| --- | --- | --- |
| 图标与文字、紧密关联控件 | 8 | 同一行使用一致间隔，文字占剩余宽度 |
| 同组条目与辅助信息 | 12 | 用间距表达关联，避免每行再嵌一张卡片 |
| 表单字段、预览网格 | 16 | 网格复用 `ResponsiveContentGrid`，随文字缩放减少列数 |
| 页面左右边距、分区标题左右边距 | 20 | 标题与正文起点对齐；实际主题列表条目沿用 18 的内边距 |
| 大分区、加载与错误状态外侧留白 | 24 | 分区优先使用标题、留白和细分隔线 |

按钮、输入、弹窗已有专用内边距，复用组件即可，不将所有内部留白替换为页面边距。尺寸使用 Flutter 逻辑像素；文字样式再由系统 `TextScaler` 缩放，不按设备像素比手动放大。

设置列表外侧使用 20，直接放在其中的说明与分区标题不再重复增加水平留白；`SectionHeading.padding` 可在已含页面边距的容器中只保留上下间距。条目的图标、文字和输入表面的内部留白继续由控件持有。模块详情字段名使用辅助文字颜色与标签样式，字段值保持可选择的正文；技术内容不因层级调整省略。

| 信息层级 | 使用样式 | 内容规则 |
| --- | --- | --- |
| 工作区日期与页面主标题 | `WorkspaceTypography.titleStyle`：24、w700、行高 1.15、字距 −0.6 | 最多三行，按可用宽度和当前文字缩放测高 |
| 分区标题 | `SectionHeading` 的 `textTheme.labelLarge` | 轻量辅助色，标题动作保持可访问标签 |
| 条目标题与正文 | 当前主题的 `titleMedium`、`bodyLarge`／`bodyMedium` | 不为整页硬编码字号；长正文自然换行 |
| 辅助信息与输入说明 | 当前主题的 `bodySmall`／`labelMedium`、`onSurfaceVariant` | 不以减小字体代替布局调整；错误信息保留文字原因 |

## 页面状态与操作反馈

状态由数据和操作的真实结果决定，宿主与控件保留交互、草稿及无障碍状态。下表是新页面与修改页面的验收要求；业务模块优先复用现有加载、错误和通知组件，逐页检查实际行为。

| 状态 | 呈现 | 保留与恢复规则 |
| --- | --- | --- |
| 首次进入、尚无内容 | 使用宿主现有加载占位与首次就绪门控 | 保留标题空间；可重试失败不得永久停在加载态 |
| 已有内容正在刷新 | 保留现有子树、滚动与输入，沿用宿主进度提示 | 普通查询不得反复整页入场；日期切换遵循统一过渡规则 |
| 查询成功但为空 | 描述当前范围为何为空，提供适用的新增或调整筛选入口 | 空数据不同于查询失败，不显示错误配色 |
| 字段校验失败 | 在相关字段附近显示原因 | 保留输入、选区和中文组合文本；焦点能回到字段 |
| 提交中 | 沿用控件外观，保护回调避免同一动作重复执行 | 不提前清空草稿、不提前展示成功；长操作使用已有进度反馈 |
| 查询或提交失败 | 页面／字段内显示原因与重试；整页错误复用 `AppErrorState` | 保留草稿和可用旧内容；重试使用当前上下文 |
| 提交成功、复制等短暂结果 | 使用 `AppToast` 或脚本 `ui.notify` | 只在实际成功后显示；需要撤销、重试或确认的操作留在可操作界面 |

后台响应必须校验页面实例和当前上下文；已经切换日期、页面或模块的旧响应不能覆盖最新可见结果。收起或离场的控件立即退出点击、焦点与辅助技术遍历，动画结束后再释放绘制资源；需要保留的输入状态不随动画重建。

## 顶栏、菜单与页面层级

- 工作区顶栏统一基准高度 56；大字体按测量后的文本高度一并扩展，避免课表和其他页面高度跳变。
- 模块可贡献当前页面标题、标题动作、返回动作及菜单操作。等待首次贡献时保留顶栏空间，不先闪现入口名；异步旧页面响应不能覆盖当前标题。
- 模块内部返回动作合并到左上角返回按钮；详情路由仍由宿主处理退出，不再重复展示“返回导入首页”等同级按钮。
- 工作区右上角只保留一个菜单按钮，合并页面操作、顶部模块入口和设置。课表切换放入该菜单；标题可用于选择教学周。
- 日程的“回到今天”放在右上角菜单首项，仅当前查看其它日期时显示，不占页面内容空间；返回目标使用概览声明的今天，菜单按钮位置作为波浪起点。
- “界面风格与恢复”位于“设置 → 外观与交互 → 界面风格”；发生界面或模块恢复错误时保留直接恢复入口。
- 脚本页面操作超过 500ms 才显示进度，快速加载及打开选择弹窗不闪条；路由被弹窗或次级页面覆盖时暂停背景进度显示。应用启动恢复另有状态提示。
- 工作区保留最近访问的最多 4 个页面，包括实际内容、输入草稿和控件状态；隐藏页暂停脚本刷新、点击、焦点和语义。首次进入等待真实首帧就绪后再切入，准备阶段保留离场内容，不用短暂加载动画替代内容。模块代数、布局或稳定上下文变化会使对应缓存失效。
- 日程日期、课表教学周与普通工作区标题共用 24px、w700、1.15 行高和 −0.6 字距，窄屏及系统大字号最多三行并按实际文字测高。
- 日程顶栏的年／月／日／星期按实际标题分段，只有变化字段作 280ms 上下翻页：向未来上滚、向过去下滚，月份不变时保持静止。跨行重排或自定义标题回退为完整轻移淡入；减少动画与高对比模式即时更新，辅助技术只读取当前完整日期。
- 连续且能完整放下的五天日期栏保持选中日居中，重叠日期保留控件；支持点击日期与左右拖动，松手最多选择一次声明中的日期。日程工作区的日期栏随就绪内容统一淡入，不叠加独立的平移或选中背景动画；独立概览仍使用 320ms 平移并从当前坐标续行。大字号放不下时保留横向浏览，明确点击才切日期；不生成模块尚未查询的任务数。日期选择先更新共享展示上下文，再查询任务／课程，旧结果及旧上下文排队事件不能回退最新日期。
- 日期刷新先捕获一份旧内容截图，普通模式以 120ms 淡出；点击立即从按钮位置产生 480ms 的柔和背景波浪。所有内容区块准备并完成首帧后，最新内容统一以 180ms 淡入，内容就绪不等待背景波浪结束。滑动使用相同的内容淡出／淡入，不产生点击波浪。五天栏及业务点击、焦点与语义在等待和淡入期间暂停；顶栏、箭头、菜单和显式导航仍可连续改变目标。快速连续选择复用一份旧截图，仅最新就绪目标完成内容过渡；减少动画及高对比模式在有旧截图时保留旧画面，直到完整内容就绪后直接替换；未满足截图条件时使用画布遮罩等待。任务新增／完成沿用各自反馈，不触发日期波浪。
- 日期工作区在空闲时逐项预取前后一天，每个脚本贡献最多保留 5 份结果，30 秒内且不过分钟边界。键包含实际实例、完整上下文、状态与表单；写提交同步失效，模块变化／恢复前台也失效。预取只允许查询和纯读取，不执行命令、弹窗或订阅；结果不清空草稿，不发布后台状态。缓存命中省去工作流查询，未命中仍异步准备，不能保证所有日期零等待。
- 日期过渡保持一份真实控件树；仅在旧内容边界已完成绘制且尺寸有效时捕获截图，按目标 4MP 和最高 2 倍像素比控制大小，连续选择不再次捕获。背景波浪共用一个 ticker，80ms 内合并装饰反馈，最多同时保留 3 个波浪；日期意图不合并或丢弃。当前实现不对文字和内容进行透镜采样，不使用亮色边缘和整页纹理网格。绘制先画实时子树，再在非导航区域叠加画布色遮罩与旧截图；遮罩随最新就绪内容的淡入进度减弱，背景波浪在不透明内容下方继续到期。标记的实时导航区域排除遮罩、旧截图和波浪，始终显示当前控件。截图在内容淡入完成后于帧末释放。业务交互门控使用同条件的 `IgnorePointer`、`ExcludeFocus` 与 `ExcludeSemantics`，覆盖默认 `DateReveal`、宿主脚本业务分支及五天栏；显式日期导航保留点击与键盘操作。进入过渡会让已聚焦的业务控件失焦，结束或取消后恢复可聚焦；焦点门控保留其当前子树，宿主继续保留输入 controller 和草稿，不自动抢回原焦点；脚本查询刷新可能按既有行为更新内部控件树，不承诺跨日期保留每个内部 State 实例。具体行为以 `date_reveal.dart` 和 `script_page.dart` 为准。
- 设置首页按“外观与交互、布局与导航、模块与连接、辅助工具、关于序点”进入二级页，首页展示当前状态；模块设置通过模块提供的入口访问。

## 动效选择

每种动效对应具体交互语义，不使用一个通用时长覆盖所有日期与页面行为。

| 场景 | 默认时长 | 维护位置 |
| --- | --- | --- |
| 独立概览日期选中色 | 180ms | `AppMotion.dateChange` |
| 日期标题变化字段翻页 | 280ms | `AppMotion.dateTitle` |
| 独立五天栏位置续行 | 320ms | `AppMotion.dateStrip` |
| 点击日期背景波浪 | 480ms | `AppMotion.dateReveal` |
| 日期旧内容离场／最新就绪内容入场 | 120ms／180ms | `AppMotion.dateContentLeave`／`dateContentFade` |
| 脚本局部过渡／快速添加展开收起 | 350ms／220ms | 默认 `AppMotion.scriptTransition`；快速添加由 `app.views.today/main.js` 显式声明 220ms |
| 工作区切换 | 360ms | `AppMotion.workspaceTransition` |
| 底栏助手出入与胶囊尺寸联动 | 500ms | `dock_motion.dart` |
| Toast 入场／退场 | 180ms／140ms | `AppToast.enterDuration`／`exitDuration` |

新动效先判断是状态变化、内容就绪还是操作反馈，再选择现有组件与时长。快速反向或连续操作从当前进度续行，动画不承担业务提交、数据有效性或首次就绪的判断。减少动画使用 `AppMotion.duration` 或组件现有即时路径；内容仍须通过就绪门控，跳过动画不跳过数据等待。日期标题、日期条和内容过渡在高对比时使用即时路径；玻璃表面使用实色并停用模糊，不因此停用所有动画。`AppMotion.disclosure` 目前是未被调用的 220ms 常量，不能据此推断 Flutter `ExpansionTile` 的实际时长。

## 宽度、文字与键盘

- 小于 820px 使用移动底栏，至少 820px 使用侧栏；窄屏主导航默认直显最多 4 个普通入口，并根据空间及文字缩放减少，其余进入“更多”。
- 工作区内容最大宽度 1040，设置详情最大宽度 760；紧凑表格和表单优先利用当前视口，不以固定宽度撑出屏幕。容器内部依据 `LayoutBuilder` 的实际约束选择布局；`ResponsiveContentGrid` 以 `680 × (TextScaler.scale(16) / 16)` 为两列门槛，不能只依据设备名称或屏幕方向。
- 移动悬浮底栏为最后一项保留可滚动余量，高度变化同步更新内容留白。键盘弹出时隐藏导航，保留输入区域。
- AI 按钮出入场与导航胶囊宽度、间隔、透明度使用同一 500ms 时间线；快速往返从当前进度反向，退出立即禁用操作与语义，减少动画模式即时完成。
- 标题和按钮适应系统文字缩放，避免固定高度裁切；密集选择可改用多列数字网格，课表默认隐藏周末并允许手动开启。
- 编辑输入保留中文输入法组合文本，提交或重绘不能清空尚未提交的内容；操作失败需保留可重试草稿。
- 日程课程区默认突出正在或下一节课程，其他课程通过“全部课程”展开，切换日期恢复紧凑状态；数量仍代表当日完整课程，避免课程列表把任务正文挤出首屏。任务副标题缩短同年和同日日期，但精确截止时间、跨日结束日期与时区不得省略到产生歧义。
- 规划拖动期间延后普通后台页面刷新，结束后合并刷新；用户明确发起的操作仍进入正常校验、审核与提交。边缘自动滚动使用帧同步、按实际时间计算位移，不用固定周期计数模拟速度；减少动画不应取消必要的直接操控反馈。

## 弹窗尺寸与留白

宿主默认弹窗由 `AppDesign` 集中设置逻辑尺寸：外侧左右 16、上下 24，宽度上限 760，短确认按内容取宽（默认最小宽 280，受实际可用视口约束）。不强制所有弹窗占满宽屏；下载与安装审核、模块详情、影响确认和宿主表单采用各自内容宽度，并受共同上限约束。

核心弹窗的标题内边距为左／右／上 20、下 0，内容为左右 20、上 16、下 20，操作区为左右 12、下 12。这些数值是标准字号配置；Flutter 随大字号自动缩减部分内边距，正文保持系统字体缩放。320 逻辑宽、无额外安全区、标准字号下，复杂弹窗正文可用宽度为 248（原默认外侧 40、内侧 24 时为 192）。共享值见 `client/lib/core/ui/ui_design.dart`。

键盘和系统安全区在外侧留白之外继续避让；长内容局部滚动，确认与取消位于独立操作区，不用固定高度裁切正文。特殊浮层可显式覆盖尺寸，界面包也保留自身配方；新建或修改宿主弹窗应复用上述常量。UI 包不得因此移除审核内容或操作。窄屏、横屏、大字号、键盘和宽屏的自动化验证见 [第二批记录](VERIFICATION.md#2026-10-13-商店布局弹窗与数据审核第二批完善)；ARM 真机缩放原因及视觉校准仍待 DISPLAY-01。

规划新建任务面板使用紧凑间距和较低的初始高度，描述、截止时间与详细规则按需展开；保存操作保持独立，低高度和大字号时正文可滚动，草稿不因展开或刷新丢失。

## 可访问性与维护

- 图标操作提供可读标签，交互目标至少满足 Material 的 48px 基准；键盘焦点、选中和错误状态都应可辨识。
- 跟随系统减少动画；高对比模式使用更清晰的实色控制层，必要时关闭模糊。错误及空状态给出原因和可执行下一步。
- 标注仅展示静态 UI 元数据，不读取输入正文或密钥，不自动截图或上传。页面槽位、入口编排和上下文失效细节见 [UI 组合](UI_COMPOSITION.md)。
- 当前设置层级见 [设置说明](SETTINGS_HIERARCHY.md)；旧 v2 设计与验收保留在 [2026-10-02 历史记录](archive/UI_DESIGN_SYSTEM_20261002.md)，不作为当前模块协议。

## 全局短暂反馈

原生页面与脚本页面共用顶部 Toast，用于保存、复制及操作结果等短消息；字段校验和持续错误保留在原页面，需要撤销、重试或确认的提示保留相应操作。默认采用 20 连续圆角、顶部安全区加 12 留白、最大宽度 440，入场 180ms、退场 140ms；减少动画直接显示／移除。同一时刻只展示一条，不同提示替换，相同正文与状态在展示期间去重且不延长计时。完整 UI、生命周期、调用和示例验收见 [全局 Toast 规范](design/TOAST.md)。
