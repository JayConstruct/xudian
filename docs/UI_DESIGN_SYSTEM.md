# 序点界面设计系统

状态核对日期：2026-10-02。当前界面使用 v2 模块架构；实现进度见 [项目首页](../README.md)。

## 方向

界面以任务内容为中心。画布使用低饱和中性色，控制层使用轻微透明和柔和阴影。导航、任务行与弹窗通过间距和 Surface 亮度建立层级，避免密集边框。浅色与深色模式共用组件和布局规则。

## 当前实现

- `client/lib/app/design_system.dart` 定义画布、品牌色、圆角、浮层与任务信息行。
- `client/lib/app/app.dart` 统一 Material 3 的颜色、输入、卡片、弹窗、菜单和按钮主题。
- `client/lib/app/app_shell.dart` 按窗口宽度提供侧栏/底栏和轻量页面标题：小于 820 使用底栏，至少 820 使用侧栏；AI 在至少 1100 的宽度显示侧面板，其他宽度显示 Sheet。
- 默认导航为“今天、收件箱、项目、模块”，AI 使用顶部入口；移动端导航超过四项时提供“更多”。任务基础编辑已支持标题、优先级与计划/截止日期：小于 820 使用底部面板，至少 820 使用右侧模态面板；非模态列表/详情分栏、看板和完整编辑器尚未实现。
- 移动底栏由 `client/lib/app/mobile_bottom_dock.dart` 渲染：快速输入与导航共用玻璃面板，半透明渐变、18px 背景模糊、细边缘高光和柔和阴影；面板悬浮在内容上方，列表通过 `WorkspaceContentInsets` 留出末项滚动空间。
- 选中项使用实心图标、略粗文字和滑动胶囊，切换约 220ms；按压轻微缩小并提供水波纹，导航切换触发轻触反馈。适配浅色/深色、大字和高对比模式，系统减少动画时关闭位移/缩放过渡。
- 键盘弹出时隐藏导航，保留贴近键盘的快速输入；空文本时提交按钮禁用，提示文字显示当前添加页面。底栏高度变化用平滑动画处理。
- 项目详情底部提供专属任务输入，自动关联当前项目；与主输入共用 `QuickTaskInput`。提交中禁用重复提交，错误使用 SnackBar，保留失败草稿与提交期间的新草稿。
- 内置任务视图和声明式任务视图都使用 `TaskObjectTile`，由客户端决定字体、颜色、状态和 Hover 反馈。

## 页面层级与设置

- **画布**：浅色使用冷灰、深色使用低亮度灰蓝，作为页面底色。
- **标题与分组**：主标题直接置于画布上；数量、分组名和说明使用较小的次要文字，项目与模块页的操作使用柔和填充按钮，避免重复大标题。
- **内容**：任务、项目及设置分组使用实色 Surface 与一致的边距；完成任务降低背景和文字的视觉权重。任务列表显示待办/完成数量，空状态提供图标与下一步说明，留出底栏遮挡空间。桌面内容宽度限制为 1040，设置详情为 760。
- **悬浮操作**：玻璃、模糊与阴影集中用于底部输入/导航和桌面辅助面板。对话框与 Sheet 承载临时选择或次级操作。
- 设置入口位于移动端标题右侧、桌面侧栏底部，打开独立页面并保留工作台与输入草稿。
- 设置包括跟随系统/浅色/深色主题、减少动画、导航触感、AI 连接、模块管理及关于/本机数据说明。外观与交互偏好保存到 `AppSettings` 的 `ui.preferences`，无需数据库结构迁移；保存成功后即时应用，系统减少动画偏好始终生效。
- AI 地址/模型/API Key 在独立连接页面显式保存，设置页与 AI 工作区共用此入口；远程地址须使用 HTTPS，本机回环地址可使用 HTTP，空密钥保存会删除旧密钥。AI 工作区保留需求、生成操作与折叠的高级 JSON 编辑器。
- 模块管理分为“内置功能”和“扩展模块”：内置功能注明原生/声明式及启用状态，项目、AI、今天/收件箱提供开关，模块管理显示锁定标识并保持可用。关闭 AI 同步隐藏顶部入口、设置中的连接入口及桌面面板；关闭当前工作台视图时回退，其他导航变化保留当前页面身份，重新启用恢复目录顺序。所有视图关闭后仍可通过模块管理恢复。开关状态保存在 `modules.builtin.<id>`，关闭保留业务数据和连接配置。

## 连续圆角

矩形控件与面板统一使用 Flutter 原生连续圆角（`RoundedSuperellipseBorder`），直线与角部曲线平滑衔接。半径由 `AppDesign` 集中管理：

| 组件 | 半径 |
| --- | --- |
| 标签与筛选 Chip | 12 |
| 输入框、按钮、桌面侧栏选项 | 14 |
| 任务卡片、项目卡片 | 16 |
| 导航选中背景、弹出菜单 | 20 |
| 辅助浮层、对话框 | 24 |
| 底部玻璃面板、Sheet 顶角 | 28 |

背景、边框和阴影使用相同的 `ShapeDecoration` / Material 形状；玻璃模糊用同半径的 `ClipRSuperellipse` 裁剪，水波纹跟随对应形状。输入框使用 `ShapedInputBorder` 保留浮动标签与焦点、错误状态。Sheet 仅顶部使用圆角；圆形图标按钮和开关保持适合其交互的形状。

## 模块与 AI 页面约束

模块只描述资源与语义，例如页面标题、图标名、视图、过滤条件和字段。模块不提供全局字体、颜色、圆角、阴影或导航样式。Schema 定义可接受字段，当前客户端手写解析器拒绝未知顶层和 manifest 字段，并由运行时校验受支持资源；完整 Schema 一致性仍需补齐。非空 `layouts` 会被运行时拒绝，AI 生成页面使用客户端提供的统一任务列表组件。

未来增加分组、看板、统计块或详情区块时，应先在客户端实现并纳入组件注册表，再扩展声明式 Schema 与语义校验。模块只选择受支持的组件及低饱和辅助色语义，不提交任意样式值或可执行 UI 代码。新增组件须同时适配移动、桌面、浅色和深色模式。

AI 提案继续经过解析、权限校验、差异预览和用户确认。视觉风格由客户端渲染器控制，提示词只辅助模型生成有效配置，不能作为风格约束的唯一防线。
