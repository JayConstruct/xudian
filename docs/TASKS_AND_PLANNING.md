# 任务、日程与规划

日程用于按日期查看任务与课程，规划用于安排执行时间。需要的功能未安装或被停用时，从模块商店安装或在模块管理启用；具体操作见 [首次安装](INSTALLATION.md)。现有任务和课程不会因为切换页面或停用模块而删除。

## 查看与编辑日程

选择日期条、前后日或日期选择器浏览日期，也可回到今天。课程与有精确时间的任务按时间混排，其他任务按原分组显示；选择课程可查看详情，课程安排在 [课表](SCHEDULE.md) 中修改。

展开快速添加可为所选日期新增任务；收起后重开保留草稿。点击任务进入编辑，按页面提示保存，取消不提交本次修改。完成勾选后任务保留原时间位置与分组，以淡色、删除线和完成说明表示状态；再次操作可重新打开。已完成任务可关联到计划日、截止日或实际完成日，日期变化不等于重复创建任务。

## 安排任务

进入任务规划，用加号新建任务；名称必填，描述、耗时和截止按需配置。普通任务可以没有截止，保存任务与安排执行时间是两个操作。

长按待安排任务拖入时间表，或移动已有任务、调整结束位置；也可在详情中精确编辑。时间块位置表示实际执行起止，截止是独立期限。课程和固定任务不能直接拖改，冲突或超截止时按提示处理；取消确认不写入。

普通调整会显示操作确认；开启“快速调整”后，符合条件的单任务调整直接保存，成功后提供撤销。多任务交换、超截止等仍需明确确认。最近提示只撤销最近一次实际调整，更早记录从操作历史查看；任务已有后续修改或完成时可能无法撤销。

日期栏可跳转和回今天，横向浏览连续日期。点击日期表头可查看当日任务。缩放、列数与每日显示时段只改变视图，不重排任务；自动安排只作用于可见且尚未过去的日期，周边预加载数据不扩大安排范围。

## 批量任务与持续规则

新建时区分单次与批量。选择规则后先查看预览及未安排原因，确认前不创建任务；修改规则与返回遵循页面上的应用／取消操作。模板可复用配置，删除模板不会删除已生成任务。

持续系列在启用且 App 运行或恢复时补齐后续实例，不重新安排旧任务，不承诺关闭 App 后继续常驻。批量创建的撤销会同时撤销其持续系列，避免再次生成。详细规则见 [新建与持续规划](design/TASK_CREATION.md)。
