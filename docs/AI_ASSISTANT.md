# AI 助手

核对日期：2026-10-09。当前生产实现为 `packages/modules/app.ai` 的 v3 脚本模块；运行、授权及提交契约见 [模块宿主](MODULE_HOST.md) 和 [JavaScript SDK](MODULE_SDK.md)。

## 入口与连接

- AI 提供应用内悬浮入口与工作区页面；启停由模块管理控制，停用保留已保存数据。
- “模型连接”配置 OpenAI Chat Completions 兼容地址、模型和 API Key，由设备直接请求用户指定服务。
- 远程连接仅允许 HTTPS；localhost、127.0.0.1 和 ::1 可使用 HTTP。宿主禁止重定向，并限制请求容量和超时。
- 端点、模型与凭据句柄保存在 AI 的 `connections` 集合；API Key 写入系统安全存储。`host_meta` 只登记凭据所属模块、端点和安全存储别名。
- 脚本通过句柄请求认证，不能读取密钥正文；宿主检查模块身份及目标地址后注入 Bearer 认证。

## 普通聊天与工具

助手从宿主服务目录获取已启用且声明 `tool` 的服务，再转换为模型的 `tool_calls`。实际可用能力随安装和启用状态变化；任务、课表、外观、布局和导航能力由各服务提供，没有相应工具时仍可普通聊天。

1. 用户发送文本，模型获取系统提示、近期对话和工具定义。
2. 首次调用工具时请求明确服务范围的授权，默认有效 30 分钟、最多 20 次写入。
3. 查询经服务权限校验返回结果；写入先 `prepare`，展示实际计划并由用户 `review`，确认后 `commit`。
4. 工具结果会继续发送给模型；每次发送最多 8 轮模型请求、24 次工具调用和 20 次写入。

相同服务及参数的重复调用复用本次结果；工具调用 ID 对应内容变化会报错。授权和计划绑定真实模块实例，过期、撤销、停用或基线变化时拒绝继续提交。

发送内容包括用户消息、最近最多 40 条对话、工具定义及后续工具结果。查询返回的业务内容可能进入模型上下文；当前没有逐字段发送预览或独立项目范围选择器。API Key 不进入模型消息。

## 高级模块开发

- 高级模式发送需求与已启用服务目录，要求返回 `{definition, files}`，其中定义为 v3、文件为模块源码。
- 生成结果和手动粘贴的源码都进入包准备与审核流程；更新必须提升版本，不能覆盖相同版本的不可变包。
- 宿主校验文件、定义、兼容性、依赖和权限，展示实际变更后才安装。源码使用隔离的 QuickJS 与 SDK 能力边界，不能直接执行系统命令或任意原生代码。
- 包格式、编辑器及预览的完整约束由 [模块 SDK](MODULE_SDK.md) 和 [公共 UI 与界面包](UI_COMPONENTS.md) 维护。

## 记录、取消与撤销

- 对话通过 AI 的 `history` 集合保存，保留最近 100 条消息；清空历史不撤销业务变更，也不删除第三方模型已收到的数据。
- “取消当前操作”终止在途网络请求并撤销当前工具授权；模块停用也关闭相关请求和授权。已提交操作仍然保留。
- 仅当服务声明 `tool.undo`、计划包含单条写入且有修改前记录时，提供临时的“撤销上次操作”。撤销仍需准备、审核和当前状态校验。
- 创建、导航和不满足上述条件的操作没有通用撤销；单次撤销也不会自动补偿被业务事件触发的规则或其他后续效果。
- 请求按顺序执行；后续失败会保留已提交结果，不能视为整段对话的一次事务。
- 重启可读取已保存对话，但不会恢复授权、在途请求、未提交计划、临时撤销或后台执行。历史不是任务队列，当前不自动重放中断操作。
