# 项目待办

本页是剩余任务的状态入口；专题只维护规则、约束与验收条件。核对依据为仓库已有实现和验收记录，本轮整理没有新增功能或设备验证。

状态含义：**待设计**为边界或方案尚未确定；**待实现**为已知功能缺口；**待设备验证**为已有实现但指定平台／场景未完成验收；**待排查**为需先核对当前调用链或采样，尚不作为已复现缺陷。
