# 课表显示设置

课表模块 1.6.3 在「课表页面菜单 → 显示设置」和「课表设置 → 显示设置」提供悬浮面板，课表始终显示在面板下方，调整时实时预览。默认仅显示周一至周五，开启「显示周六和周日」后显示七天；五天和七天均分剩余屏幕宽度，节次栏固定，不需要横向滚动。已有周末课程保留，周查询、今日课程和备份仍包含周末数据。页面菜单中的「周末课程」可在本次浏览临时展开周末，不改写已保存设置。

滑块向左压缩、向右拉高所有节次，`−1`、`+1` 两个按钮每次精细调整总高度1个逻辑像素，在上下限禁用相应按钮；日期栏保持48。以12节课表为例，默认总高度912，范围为624–1968。

每节显示高度在48–160之间，默认72。面板右上角的「关闭显示调整」隐藏面板；未保存时关闭会恢复课表的已保存高度和周末显示设置，草稿在当前会话保留，再次打开可继续编辑。「恢复默认高度」仅修改高度草稿，点击「保存显示设置」并完成宿主数据审核后持久保存。取消审核保留草稿；「重新载入」丢弃草稿并读取已保存值。主课表的菜单可重新打开面板，设置入口每次进入也会打开面板。

高度和周末开关以可选 `rowHeight` / `showWeekends` 字段保存在当前课表中，重启后保留，不同课表可以使用不同设置，JSON 备份包含这两个值。旧课表省略字段时使用默认高度并隐藏周末，无需迁移；修改节次数时，总高度随节次数调整。保存会检查高度和周末设置是否被外部修改，避免覆盖其他页面的设置。

通用悬浮面板由宿主 API 1.5.0 提供，五天／七天适配屏幕的 `fitColumns` 需要客户端 build 34 或更新版本（当前建议 build 36）。早期同为宿主 API 1.8.0 的客户端会忽略此选项，七天表格仍可横向滚动；需先更新客户端，再导入 [独立模块包](../dist/modules/app.schedule.xmodule)。面板内可滚动，关闭按钮始终可见，未被面板遮挡的课表继续支持滚动和课程点击。调高或关闭面板不改变课表视口大小。紧凑课程标题保留1.4.1的最大高度限制，完整信息仍可通过详情查看。
