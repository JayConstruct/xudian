# 性能排查与平台验收细则

任务状态统一在 [项目待办](../BACKLOG.md) 维护，本文提供调用链证据、场景与验收条件。既有实现结果与旧设备状态见 [验证索引](../VERIFICATION.md)，有效 UI、安装和审核规则分别由 [界面规范](../UI_DESIGN_SYSTEM.md)、[安装反馈](../MODULE_CATALOG.md#安装流程反馈)、[数据审核](DATA_CHANGE_REVIEW.md) 维护。

## 待实现与待测性能项

下表来自既有代码排查，属于待处理或需重新采样的入口；结构性成本不等于已复现真机卡顿，实施前先核对当前代码。

| 任务 | 已记录的触发入口 | 后续方向 |
| --- | --- | --- |

| PERF-04 大模块保存审核 | `app_shell.dart` 的 `packages.review` 将新旧定义、源码与预览交给 `host_dialogs.dart`；后者在界面构建时缩进编码并用单块 `SelectableText` 展示 | 按文件与变更组织审核，后台准备并有界呈现；保留完整内容、复制、隔离预览与摘要绑定 |

| PERF-09 大目录与版本索引解析 | `catalog_client.dart` 同步 UTF-8 解码、JSON 解析、模型校验；`ModuleVersionIndex.fromJson()` 同步解析全部版本并排序。联网元数据最大 4 MiB，限制请求并发没有把单份重计算移出 UI | 大元数据在后台解析／校验／排序，保留仓库绑定、无效格式拒绝、缓存和加载世代隔离；先采样大目录 |

## 设备验收缺口

| 关联任务 | 剩余场景 | 判断依据 |
| --- | --- | --- |
| PERF-01／02 | 源码编辑、商店及详情的大数据量帧率 | 自动化及加载结构优化已完成，需真实设备录制，不能以调用数推算 FPS |
| UX-01 | 弱网、未知长度、缓存命中、快速下载、取消及失败重试 | 进度必须对应真实阶段和字节，未知总量不伪造百分比，重试保持批次计数 |
| UX-02／03／06 | 大批安装与数据审核、长名称、窄屏大字号和实际读屏 | 主要安装／导入／取消已在设备复验；展开仍可核对完整计划，删除与关键字段不能遗漏 |
| UX-04 | 单次及批量安装 Toast 时序与视觉 | 仅事务成功后通知，批次准确合并；Toast 消失后仍有持久打开入口，失败可继续处理 |
| UX-05 | ARM 真机大字号、横屏、键盘与读屏；桌面复杂弹窗 | 表单／草稿／取消及模拟器 1.5 字号已验，真机 ROM 拒绝字号写入，不能声称真机大字号已通过 |
| UX-07 | Windows 原生时区、系统时区切换、跨日和 DST | 新建默认系统时区；旧课表保留原时区，备份与来源语义见 [时区规则](TIMEZONE_DISPLAY.md) |
| UX-08／STYLE-01～07 | 原生教务浏览器、脚本提示框浅深色、跟随系统、窄屏／大字号及返回 App 系统栏恢复 | 宿主主题桥接已实现；学校网页配色独立，横屏键盘是否挤占网页需实测，不能列为已证实缺陷 |
| DISPLAY-01 | 新页面显示密度、字号、留白和逻辑视口对照 | 原 ARM 480 DPI／模拟器 420 DPI 已解释比例差异，不归因于 CPU 架构；不禁用系统字体缩放，比较后恢复设置 |
| UX-09 | 规划剩余交互与原型校准 | 以 [规划交互](PLANNER_UX_REDESIGN.md) 的未定边界和 [任务新建](TASK_CREATION.md) 为准；不再将整页标记为“尚未实施” |

跨模块业务名称元数据和减少重复审核仍需通用设计；不能为减少弹窗取消必要审核。大量记录／长嵌套原始详情与代码显示沿上方 PERF-04／07／08 分别验收。

## PLATFORM-01：Windows

1. 验证构建与安装、QuickJS 和模块加载、文件、安全凭据、网络下载及更新。
2. 验证窗口缩放、宽屏多列、滚轮、焦点、快捷操作、文件选择及弹窗。
3. 实际从商店安装并走通任务、课表、JSON 导入、规划和 AI，覆盖返回、重开、重启及数据保留。

浏览器采集目前只实现 Android，Windows 需明确受限能力。交付独立能力矩阵，构建成功不代表业务流程通过；其他桌面平台范围另定。

## SYNC-01：多设备同步

沿用本地优先、端到端加密、用户保管恢复码及后续自有云适配器方向；与桌面适配独立设计。

- 明确业务数据、偏好、模块版本／安装状态的同步范围，稳定标识、迁移、删除记录、增量和冲突规则；密钥及设备凭据不作为普通业务数据直接同步。
- 设计账号／设备加入、加密、恢复码、自有云、离线队列、幂等重试、设备退出和故障恢复。
- 提供首次合并预览、冲突处理、状态、重试和恢复入口，标明仅本机内容，失败不阻断本地操作。
- 验证 Android／Windows 双设备增改删、同时编辑、长期离线、重复重试、模块版本差异与恢复码恢复。

## 推进与关闭条件

先采样大包及长内容入口，再补弱网、读屏、横屏与原生浏览器矩阵；Windows 分阶段验收，同步先形成协议再实现双设备闭环。状态变更和关闭记录只更新项目待办；结论和未覆盖范围进入验证索引，公共行为只更新所属专题。
