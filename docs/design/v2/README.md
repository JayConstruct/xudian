# V2 设计总稿

本稿汇总独立 V2 的当前设计：沿用实际截图的浅色、蓝紫和柔和卡片风格，以图片和文本重新实现页面。技术方向为 Flutter/Dart 宿主与 JavaScript/QuickJS 独立模块，页面布局、业务逻辑和动画定义由模块承载；不复制旧业务 UI，不运行旧 UI 协议或旧模块包。

当前材料为 **4 页截图优化稿、19 张实际截图、26 页流程与状态规格**。四页是当前比较稿，尚未标记为最终获选，也未实现到应用。最早那轮自由重排稿已删除，不再列入总稿。

## 页面与操作

| 主入口 | 职责 | 主要流程 |
| --- | --- | --- |
| 今天 | 当天执行与概览 | 浏览日期 → 查看任务或课程 → 完成、编辑或进入规划 |
| 规划 | 任务管理与时间安排 | 新建／编辑 → 单次保存或批量预览 → 安排／拖动 → 查看结果与撤销 |
| 课表 | 周视图与课程管理 | 查看课程 → 编辑周期或仅调整本次；导入来源 → 配置与差异预览 → 确认导入 |
| 模块 | 模块、工具和应用设置 | 查看模块 → 详情 → 安装／更新；进入外观、设置、开发工具与 AI |

“更多”的工具入口整合到模块主入口，不增加中转页。UI 示例归入开发工具；AI 可由用户固定，不默认占用独立浮动按钮。

普通创建、保存、完成直接提交；普通拖动成功后提供撤销。批量、冲突覆盖、超截止风险、导入和 AI 写入先展示影响再确认。宿主仍检查权限、身份和数据版本。

新建与编辑共用渐进表单，关闭保留草稿，成功后清理对应草稿。子表返回只取消子编辑；返回页面恢复原日期、筛选和滚动位置。26 页的入口、返回、正常／空／加载／失败／保存中／返回重开状态详见[页面流程](PAGE_FLOWS.md)。

## 统一视觉

- 浅色画布 `#F7F7F4`、白色表面、蓝紫主色 `#5965A8`；正文 `#25272E`，辅助文字 `#666B78`。
- 标题／正文／辅助字号建议 28／16／14 sp，按 4、8、12、16、24、32 dp 组织间距。
- 输入和按钮圆角 16 dp、卡片 20 dp、面板 28 dp；触控区域至少 48 × 48 dp。
- 短表单自然收紧，键盘避让焦点字段与主按钮；四个主入口在小屏和大字体下均可达。
- 动效以按压、局部展开和页面切换为主，支持取消和减少动态效果；课程与任务保持真实时间几何。

完整组件、响应式与动画要求见[视觉规范](VISUAL_SPEC.md)，机器变量见 [tokens.json](tokens.json)，来源与采集边界见[截图索引](SCREENSHOT_INDEX.md)。这些数值是设计建议，不是对图片像素的机械缩放。

## 模块边界与实现顺序

模块拥有页面、文案、字段、业务规则、样式和动画定义；宿主提供通用布局、渲染、手势、动画执行、导航、无障碍和受保护系统能力。模块需求超出现有通用能力时，才扩展宿主并声明兼容范围或回退；宿主 Dart 修改仍需更新 APK。

先实现共用任务表单与详情、时间轴和课程详情，验证保存与返回。随后在固定 APK 上连续更新模块，确认布局和交互修改可独立分发，再扩展导入、模块管理与 AI。新工程位置、独立应用标识、模块 API、数据模型和调度算法在运行实现前明确；旧应用及其数据保留，数据导入另行设计。

## 交付与验证范围

本轮仅整理设计图和文档，没有创建 V2 运行工程、更新 APK 或模块。当前四页经视觉核对；原始截图、生成原图和参考来源均保留摘要。旧版截图只证明采集时的状态，不能替代 V2 的运行验收。

拖动保存与撤销、导入提交、模块更新恢复、中文输入法、减少动画、2 倍字体、宽屏及真机性能仍需在隔离数据和实际实现上验证。详细检查记录见[本月记录](../../verification/2026-11.md)。
