## 观察结论

- S03 与 S09 使用不同的新建／编辑容器；V2 统一为渐进任务表单，短确认才使用居中对话框。
- S08 与 S15 体现相同课程信息从不同来源进入时的容器差异；V2 统一详情信息结构，返回仍回实际来源。
- S10 显示空白任务字段和英文软键盘同时可见、主按钮位于键盘上方；未验证中文输入法组合文本。
- S13 与 S14 显示字体变大或宽度变小时底栏缺少课表及规划入口。V2 的四个默认主入口必须保持可达且选中状态准确。
- S16 常用课程操作位于长内容之后，S17 在底部面板上再叠居中表单；V2 用分组摘要和同面板内子页改善操作路径。
- S18 将日常操作和开发／删除操作放在同一菜单，S19 直接显示长摘要。V2 优先呈现用途、版本和状态，技术细节展开查看。
