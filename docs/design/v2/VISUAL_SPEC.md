| 圆角 | 输入与按钮 16、卡片 20、面板 28 dp；导航及胶囊按实际高度取半高 |
| 图标与操作 | 常规图标 24 dp，点击区域至少 48 × 48 dp；主按钮最小高度 52 dp |

所有正文和辅助文字在其实际不透明背景上须达到至少 4.5:1 的对比度；必要控件边界、状态标记和焦点环以至少 3:1 为验收目标。分类色使用蓝、绿、紫、棕四组独立变量，不借用成功／危险状态表达课程归属。状态同时提供文字或图标，不能仅依赖颜色。

普通列表用间距与轻分隔分组；课程、任务及模块条目可用卡片。阴影只用于导航、面板等浮层：建议颜色 `#25272E`、透明度 0.08、向下偏移 8 dp、模糊 24 dp。静态卡片不叠加阴影。主操作填充、次操作描边、辅助操作文字按钮；每个表单只有一个视觉主操作。

一级页面标题左对齐，日期与周次使用独立视图工具栏。详情页使用带返回按钮的标准顶栏。图标使用同一套圆润线性风格，今天、规划、课表、模块采用可区分的图形，不以同一个日历图标代表全部入口。

## 页面、面板与导航约束

- 默认主导航为今天、规划、课表、模块；选中项同时使用图标、标签和浅蓝紫背景。AI 从模块入口或用户固定入口进入，不另设挤占导航宽度的独立圆钮。
- 四个默认主入口在小屏和大字体下保持可达且不得被溢出裁掉。两倍字体优先收紧项内水平留白、允许标签两行并增高底栏；保留最小命中区域，不缩小系统字号。选中态按稳定入口身份计算，布局压缩不能把规划页映射为更多或其他项。
- 浮动导航默认最小高度 72 dp、外侧间距 12 dp。实际高度随文字和系统缩放增加，位置包含系统底部安全区。内容尾部留白为实际导航遮挡高度加 12 dp，最后一项必须能完整滚入可视区域。
- 内容可以在导航后方继续绘制，但导航与面板必须阻止点击穿透。任务卡片、时间段和操作按钮不能只有被遮挡的命中区域。
- 短信息和确认使用对话框；新建、编辑使用同一套底部面板。面板短内容自然收紧，长内容最高占可用高度的 90% 并内部滚动；可用高度扣除系统安全区和键盘。
- 面板内选择日期、属性或规则时使用同一面板的内部返回。系统返回先关闭键盘，再退出内部选择，最后关闭面板。关闭与返回不能隐式执行保存或业务写入。
- 新建草稿按流程约定保留，编辑只有显式保存才写入业务数据；成功后清理对应草稿，失败保留输入并提供重试。取消、未修改、保存中、保存失败必须有各自状态，不能只画成功页面。
- 弹窗打开时背景退出交互和无障碍焦点遍历，关闭后焦点回到来源控件。错误提示靠近出错字段，整体操作错误在面板内展示，不靠短暂提示替代纠错说明。
- 键盘显示时隐藏主导航。表单主操作位于键盘上方且不遮挡焦点字段；垂直空间不足时主操作随表单滚动，不能把可编辑区域挤成不可用高度。

## 响应式、大字体与动效

| 可用宽度 | 布局规则 |
| --- | --- |
| 小于 600 dp | 单栏内容与底部导航，表单横向填满可用区域 |
| 600–839 dp | 表单最大宽度 560 dp、普通阅读内容最大宽度 720 dp；时间网格使用剩余宽度 |
| 至少 840 dp | 主导航转为 80 dp 起的侧栏，列表与详情可并列；表单仍限制 560 dp，不把字段无限拉宽 |

以上是内容布局约束，不代表已完成平板或桌面验收。最小验证宽度为 320 dp，并覆盖 600 和 840 dp 边界。字体缩放至少验证 1.0、1.3、2.0 倍：文字自然换行，按钮与导航允许增高，顶部次要动作进入菜单，不隐藏关键操作。日期条保留单项可读尺寸并横向滚动，选中日期自动保持可见。

时间轴遵守真实时间几何。文字放不下时保留标题或明确摘要标记，通过可访问的详情入口查看全文；不能通过增高短任务块伪造时长。课程卡片优先保留名称，其次地点和教师；辅助字段不足时进入详情，不把字号缩到 12 sp 以下。

| 动效用途 | 建议时长 | 执行规则 |
| --- | --- | --- |
| 按压／即时反馈 | 120 ms | 不延迟真实动作，松手或取消可立即反向 |
| 局部状态与展开 | 180 ms | 仅变化区域参与，不重播整页入场 |
| 页面／面板切换 | 260 ms | 页面身份稳定，快速返回可取消过渡，离场节点停止交互 |

进入和局部变化采用 `cubic-bezier(0.2, 0, 0, 1)`，退出采用 `cubic-bezier(0.4, 0, 1, 1)`。连续拖动跟随输入，不用固定时长插值追赶手指；松手后的吸附再使用状态过渡。开启减少动态效果时，位置、缩放和视差立即到终态，透明度过渡最多 80 ms，不循环播放装饰动画。加载结果未完成时仍展示真实加载状态，不能用动画掩盖未成功的业务操作。

当前可确认的旧版观察包括截图索引中已采集的 S01–S09 基础页面、S10 英文键盘展开，以及 S13／S14 的大字体和小屏状态。对比度可针对本规范变量计算检查；中文输入、全部表单键盘避让、导航遮挡、手势与动画取消、无障碍及响应式仍须在未来 V2 原型中实测，不能将旧版截图或本规范标记为 V2 已通过。
