# 任务新建、规则与持续规划

任务规划模块 1.7.1、宿主 API 1.37.0 将新建任务分为单次和批量。
主页面保留名称、描述、耗时、规则摘要和安排设置；模板、规则及预览使用独立标题和返回操作。

## 新建与模板

单次任务可设置描述、耗时与可选截止日期／时间；保存不擅自填入计划时间或截止日期。
批量任务选择规则后先预览，确认前不创建任务。确认按钮绑定当前冻结计划，实际变更详情由宿主显示。

模板使用无图标文字列表，按「内置／我的模板」分组，支持搜索。点击套用返回草稿，已有输入时明确确认替换。
「存为模板」放在页面更多菜单中，个人模板保存在模块界面偏好中；删除模板不删除已经创建的任务。
模板保存任务配置，不保存任务实例、完成状态和历史绝对日期；套用时首次日期按当天计算。

子页面通过 `replaceForms` 同步真实草稿和输入控制器，各自保留滚动位置。
规则编辑保留隔离草稿，应用后才更新新建表单，返回则放弃本次规则修改。

## 规则与预览

当前新建入口支持间隔安排、每日安排、允许星期、允许时段与优先级。
每日和间隔安排互斥；未接入批量服务的规则不显示为可用能力。
规则子页支持分类搜索、已选项配置及移除。

批量窗口为规则时区内的当天至第29天，含首尾共30个自然日，与时间轴显示列数和任务截止日期独立。
首次安排日期限制最早生成日，不改变滚动窗口。默认间隔4～6天、工作日、18:00～22:00，每次30分钟。
算法使用真实任务、课程、手动占用及缓冲，避开当前已开始的分钟；时区转换有歧义时拒绝该安排。

预览显示可安排与未安排数量、日期窗口和原因，支持修改单次日期及起止。
必须处理未安排项后才能确认创建，不静默省略必需任务。

## 手动调整与持续补齐

预览和已生成批量任务均支持「仅本次／本次及以后」，显示受影响实例与前后间隔。
联动保留后续各自的实际耗时，碰到后续已手动安排时拒绝覆盖并提示处理。
提交前重新检查占用、任务快照、星期、时段及相邻间隔，确认计划过期时要求重新预览。

确认生成会保存独立系列及稳定实例序号。自动补齐只新增缺少的后续实例，不重排旧任务，不重复生成。
宿主通过可信 `app.host / host.clock.tick` 在启动、恢复前台、启用模块及前台每分钟触发已授权规则。
它使用模块安装授权的 `automation.execute` 与现有自动化事务流程；查询与页面渲染本身不写数据。
脚本伪造同名时钟事件无效。相同分钟去重，空操作不提交和记录历史；停用、后台和关闭时停止计时器。
应用关闭时不承诺操作系统后台常驻；重新打开或恢复时补齐当天向后的30天。

多个系列在同一轮续排共享新增占用。单个系列受阻不会阻止其他系列；释放占用后可再次补齐。
长期未启动时保留过期未完成任务，从当天继续后续规划，不把历史未完成项标为完成。
撤销批量创建同时撤销其持续系列，避免撤销后自动重新生成。

## 通用宿主组件

API 1.37.0 增加声明式 `segmented`、`formSection`、`notice` 与 `choiceCard`；`card` 支持 `tone`，
`listTile` 支持选中背景和强调尾部文字，搜索输入可用 `showSearchIcon:false`。
根节点 `scrollKey` 为子页面隔离滚动位置。详情和面板顶栏支持标准 `header.actions` 菜单及快捷入口。
分段选择在窄屏和大字号时换行，固定操作区与正文滚动区分离。
