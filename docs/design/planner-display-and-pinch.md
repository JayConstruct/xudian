# 任务规划缩放与详情显示

设计先于新增功能实现，后按本轮模拟器现有页面校准。设计稿左侧嵌入更新前实际截图（2026-11-04），右侧使用现有模块表单、卡片、勾选项和返回导航表达新页面。主色沿用 AppDesign 的 #5965A8；时间轴、课程颜色和底部半透明导航沿用现有组件。

- 双指缩放仅改变纵向时间密度，以双指中心为锚点；单指滚动、日期列数与任务时间不变。保留菜单缩放与可访问操作，保存缩放偏好。
- 拖动统一5分钟增量，横向只换日，不再触发精细模式；手工输入的非整5分钟时间保留起点偏移，精确编辑使用原时间编辑页。
- 页面菜单 → 视图与显示 → 详情显示，使用既有自适应面板页面，关闭返回后保留原视口。模块声明配置、文案与偏好；宿主提供通用缩放与详情行渲染。
- 所有课程卡片可统一显示地点/老师。选中详情可分别控制地点、老师、来源、空闲时段；标题与时间常显，缺失数据不占位。自动保存，可恢复默认。

## 遗留体验修正

新增修正稿见 [显示一致性修正](planner-display-refinement.svg)。两个预览分别展示课程卡片与选中详情，分别跟随对应开关，来源与空闲也提供示例。当日任务列表复用相同地点／老师标志，辅助行根据内容增长，隐藏字段不占空行。日列表拖放按5分钟定位，手动填写起止仍按任意分钟处理。模块声明允许的拖动意图，课程、固定或已完成目标不触发交换；未开放的插入顺延回到普通移动和占用校验。

菜单返回的时序修正：横向滚动后，菜单操作需先保存视口偏好。原生菜单退出时，工作区已重新成为当前路由，但页面活动依赖可能晚一帧更新；此时先等该帧恢复，再核对同一模块、上下文和顶栏租约后派发。切换工作区、失效租约或被新路由覆盖时仍不执行旧动作。对应实机路径为“拖动取消 → 视图与显示 → 详情显示”。
