# UI 规则核对记录

日期：2026-10-14。核对当前 Flutter 公共实现、宿主布局与设计文档。规则入口为 [界面设计系统](../UI_DESIGN_SYSTEM.md)，风格场景为 [柔和极简界面](SOFT_MINIMAL_UI.md)。本轮统一规则和来源，并补齐日期过渡的键盘焦点门控；视觉绘制与动效节奏保持现有实现。

| 日期绘制与门控 | 容易将背景波浪理解为内容揭示，以及把点击屏蔽当作焦点屏蔽 | 当前实时子树上叠加画布色遮罩和旧截图；内容就绪后逐步撤下遮罩，实时导航区域排除遮罩与波浪。原业务门控仅使用 `IgnorePointer`、`ExcludeSemantics`；本轮补上同条件 `ExcludeFocus`，避免键盘触发遮罩下的业务操作，显式导航仍可聚焦 |
| 动效降级与展开时长 | 容易将减少动画当作跳过数据等待，将 220ms 常量当作 `ExpansionTile` 的实际时长 | 日期即时路径仍等待内容就绪；玻璃表面高对比仅停用模糊并使用实色。快速添加由模块显式声明 220ms，`AppMotion.disclosure` 当前未被调用 |
| 字体规则入口 | 规则包含标题数值，但未指出共用实现 | 明确 [`WorkspaceTypography`](../../client/lib/core/ui/workspace_typography.dart)；普通正文使用当前主题，保留 UI 包与系统字号 |
| 界面包 `spacing` | 容易被理解为所有页面的间距缩放 | [`applyUiPackTheme`](../../client/lib/core/ui/ui_component.dart) 当前调整列表条目留白，recipe 内另有具体 spacing；文档明确作用范围 |

## 补齐的可执行规则

- 按 8／12／16／20／24 的使用场景选间距，并明确组件内部专用尺寸和现有列表 18 的例外。
- 按工作区标题、分区标题、正文和辅助信息选择现有样式，不再在业务页复制标题实现。
- 对首次加载、刷新、空数据、校验失败、提交中、失败和成功规定呈现、草稿及重试行为；成功反馈依据实际提交结果。
- 按具体交互选择动效时长，明确内容就绪与背景装饰独立计时，以及减少动画和高对比的范围。
- 增加窄屏、大字号、宽度边界、键盘、浅深色、界面包、连续操作与无障碍的验收矩阵，并列出相关现有测试。

## 后续覆盖边界

现有自动化入口已列在主规范；其中 `ui_shell_layout_test.dart` 使用窄屏／宽屏样本，不能视为已经验证 819／820 的精确边界。新增或修改导航断点时应增加对应边界样本。网格目前依据 `680 × (TextScaler.scale(16) / 16)` 选择列数，变更后应检查局部可用宽度和系统字号，而不只检查窗口宽度。

日期过渡的默认门控、脚本业务分支和五天栏现已同时排除点击、焦点与语义。进入过渡会正常失焦，结束或取消后可重新聚焦；不自动抢回焦点。`date_reveal_test.dart` 验证等待／淡入期间不能键盘激活业务、显式导航可操作及结束／取消后恢复；`daily_date_ui_integration_test.dart` 验证真实宿主当前已挂载输入的焦点阻断与重新聚焦，以及 controller／草稿保留。对照测试确认：禁用本轮焦点门控后，真实脚本日期刷新同样会替换内部 `TextFieldState`；这属于既有刷新行为，本轮不承诺跨日期保留每个内部 State。默认 `DateReveal` 单元测试则验证门控自身不替换输入 State。旧边界未完成绘制或尺寸为空时无法获取旧截图，过渡使用画布遮罩等待，不保证始终保留旧画面。

间距表与页面状态表是新建／修改页面的验收要求，不是既有页面全部符合的证明。间距仍有主题、组件和模块声明各自的用途，本轮没有新增一套全局 spacing token，也没有批量替换有效的控件几何。之后若新增共享 token，应只迁移同一语义的重复值，并分别验证界面包覆盖和窄屏。模拟器截图与真机视觉校准仍需按具体改动执行；本记录不声明已完成本轮设备视觉验收。
