# 全局 Toast 规范

Toast 是宿主统一的短暂操作反馈。原生页面使用 `AppToast.show`，脚本页面使用 `ui.notify`；两者共用顶部浮层、关闭与计时逻辑，通过 `ui.notification@1` 接入当前界面包。组件契约见 [公共 UI 与界面包](../UI_COMPONENTS.md)，脚本权限与参数校验见 [SDK](../MODULE_SDK.md#api-112-的-ui-偏好提示和过渡动画)。

## 场景与内容

| 场景 | 呈现方式 |
| --- | --- |
| 已复制、已保存、已固定等即时结果 | Toast；只在实际操作成功后显示 |
| 操作失败，但页面仍保留上下文且可重新操作 | 错误 Toast，简短说明原因或下一步 |
| 字段格式或必填校验 | 字段附近的校验文字，保留输入内容 |
| 持续加载、离线、无法打开页面 | 页面或区块内状态，提供必要的重试操作 |
| 撤销、重试、确认、权限审核 | 保留可执行操作的页面提示或对话框 |

Toast 不承担必须阅读后才能继续的内容。文案以结果为主，避免只有“成功”或“失败”的笼统描述；失败提示不能替代页面内持久错误或丢失未提交草稿。默认消息不含跳转、撤销、重试等业务按钮，关闭按钮只移除提示。

状态只有 `info`、`success`、`error`。消息、成功分别使用信息和勾选图标，均采用主题 `primary` 色；错误使用错误图标与主题 `error` 色。正文明确表达结果，不单独依靠图标或颜色区分状态。

## 默认 UI

以下尺寸为 Flutter 逻辑像素；颜色、字体随浅色／深色主题变化。

| 项目 | 默认值 |
| --- | --- |
| 位置 | 根 Overlay 顶部居中，位于路由、对话框和面板上方 |
| 安全区 | 避开顶部和左右系统安全区，顶部额外留 12，左右至少留 12 |
| 宽度 | 最大 440；窄屏使用可用宽度 |
| 形状 | 20 连续圆角，背景、裁剪、阴影使用同一形状 |
| 背景 | `surfaceContainerHigh` |
| 阴影 | Material elevation 6，黑色 16% 透明度 |
| 内边距 | 左 16、上／下 6、右 4 |
| 内容 | 24 状态图标、12 间距、可换行正文、4 间距、关闭按钮；超出可用视口时正文局部滚动 |
| 正文 | 主题 `bodyMedium`，跟随系统文字缩放，不固定高度或单行截断 |
| 关闭 | 图标 18，提示及可访问标签为“关闭提示”，保留标准按钮触摸范围 |

浮层不占用页面布局，也不遮挡整页操作；提示以外的区域继续响应点击。键盘出现后仍在顶部安全区显示，不改为底部提示。宽屏保持居中和最大宽度，长文与大字号增加内容高度；可用视口不足时正文区域滚动，状态图标和关闭按钮保持可见。

界面包可以通过 `ui.notification@1` 调整样式和内容包装，上表描述内置默认视觉，不要求所有包使用同一颜色和间距。`content` 为宿主持有的必需槽位，只能呈现一次；包不能隐藏或复制正文、关闭操作与可访问语义。位置、宽度约束、进退场动画、计时和关闭由宿主管理，包不能添加业务操作或修改结果。

## 动画与生命周期

| 阶段 | 行为 |
| --- | --- |
| 入场 | 180ms，`easeOutCubic`；透明度 0 → 1，竖向位移从自身高度的 −18% → 0，轻微下移进入 |
| 退场 | 140ms，`easeInCubic`；反向播放，上移并淡出 |
| 减少动画 | 系统或应用开启减少动画时直接显示／移除；仍保留自动消失和手动关闭 |
| 自动消失 | 默认 3 秒，从挂载开始计时；退场动画另计 |
| 手动关闭 | 立即取消自动计时并退场；连续点击关闭只执行一次 |

同一应用根 Overlay 同时只展示一条 Toast，不排队、不堆叠；不同根 Overlay 的条目分别管理，避免多个应用实例互相替换或被旧实例关闭。不同正文或状态的新提示立即替换当前条目，再开始自己的入场和计时；旧条目的计时与动画完成回调不能移除新提示。

展示中的相同 `message` 和 `kind` 重复调用视为同一条，即使传入不同 `duration` 也不重新播放、不延长计时。提示开始关闭后再次调用可作为新条目展示。去重用于抑制重复反馈，不能用 Toast 本身判断业务操作是否重复执行。

提示保留 live region 语义，允许辅助技术播报正文，不抢占页面焦点；状态图标提供“提示”“成功”“错误”的语义标签，关闭按钮有独立可读标签。读屏是否完成播报由平台和辅助技术决定，自动计时保持一致，因此必须持续可读的信息应保留在页面中。系统大字号下正文自然换行，过长时可滚动，关闭操作仍可触达。

## 调用

原生页面：

```dart
AppToast.show(context, message: '已保存', kind: 'success');
AppToast.show(context, message: '复制失败，请重试', kind: 'error');
```

原生调用应使用有效、仍挂载且位于应用 Overlay 下的 `context`；异步任务完成后先检查页面仍挂载。`kind` 使用以上三种状态，普通短消息沿用默认 3 秒。

脚本页面需要 `ui` 权限及 `hostApi: '^1.12.0'`：

```js
await ui.notify({message: '已保存', kind: 'success'});
await ui.notify({message: '连接失败，请稍后重试', kind: 'error', duration: 5000});
```

`message` 为 1–200 字符的非空文本；`kind` 默认 `info`；`duration` 为 1000–10000 毫秒整数，默认 3000。调用返回 `null`，表示请求已交给宿主，不等待提示消失，也不产生导航或业务数据写入。允许执行阶段与 UI 偏好相同，查询、命令准备、迁移、安装验证及隔离预览不能发出提示。原生 API 的参数与脚本参数校验是不同层，脚本限制不自动成为原生 API 的校验规则。

## UI 示例与验收

在模块管理中启用“UI 示例”后，入口为“UI 示例 → 状态反馈 → 消息提示”，源码位于 `packages/modules/app.ui.examples`。演示应调用真实 `ui.notify`，底部调用方式弹窗提供可复制代码，避免静态卡片与实际浮层的行为不一致。

示例覆盖消息、成功、错误、长正文、连续替换、相同内容重复、1 秒／10 秒时长边界及弹层内调用。正常进退场使用统一的 180ms／140ms 动画；减少动画效果通过系统或应用设置实际验证，不以另一种独立动画模拟宿主效果。

| 验收条件 | 预期 |
| --- | --- |
| 浅色、深色与 UI 包切换 | 正文、图标、关闭按钮可辨识；包缺失配方时使用内置回退 |
| 窄屏、宽屏、系统大字号及长文 | 不横向溢出，不裁切正文，关闭按钮可触达 |
| 对话框或底部面板打开 | Toast 在其上方，关闭 Toast 不关闭原浮层 |
| 键盘打开 | Toast 仍位于顶部安全区，输入与页面操作可继续 |
| 不同消息连续触发 | 只显示最后一条，旧计时不会提前关闭新条目 |
| 相同正文与状态重复触发 | 不重播、不延长；同正文但不同状态按新条目显示 |
| 自动消失与手动关闭同时发生 | 只关闭一次，不产生 Overlay 或动画异常 |
| 系统或应用减少动画 | 即时显示／移除，不出现滑移或淡入淡出 |
| 读屏及键盘焦点 | 正文有 live region 语义，关闭有标签，提示不主动抢焦点 |

宿主的自动化验证应覆盖去重、替换、关闭竞态、时间线与减少动画；平台安全区、实际读屏、键盘和视觉表现仍需设备验收。
