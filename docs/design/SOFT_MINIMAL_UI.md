# 柔和极简界面

用户确认的 [今天页面参考图](soft-minimal-today-reference.png) 用于确定整体风格。应用呈现实际模块数据，课程、任务与已配置的导航入口继续由模块提供。

## 基础样式

| 用途 | 默认浅色值 |
| --- | --- |
| 画布 | `#F5F5F2` |
| 内容表面 | `#FEFEFC` |
| 主要文字 | `#303239` |
| 辅助文字 | `#6D707A` |
| 强调色 | `#606EAE` |
| 卡片圆角 | 20 |
| 控件与按钮圆角 | 14 |
| 弹窗圆角 | 24 |
| 悬浮导航圆角 | 28 |
| 页面左右间距 | 20 |

深色主题使用独立的画布、表面、文字和强调色。界面包自定义的颜色和用户选择继续生效。普通内容使用标题、间距和细分隔线分组，浮层才使用轻微阴影与模糊。

## 日程页面

原“今天／每日”入口改名为“日程”，保留原模块和页面标识。底栏使用固定入口名称，顶栏显示所选日期与星期，跨年时带上年份。概览不重复完整日期，保留日期选择、前后日、回今天、真实待办数量和五日日期条。中文日期选择器可跳转至任意日期。任务与课程共同跟随所选日期，快速添加使用该日期作为计划日期。课程分区显示课程总数、时间列与浅色课程块，点击进入原课程详情；当天临近上课时显示提示。待办分区使用简洁复选框列表，正文打开编辑，扩展字段折叠，标题加号展开快速添加。

概览、课程、待办仍是公共 daily 槽中的独立模块贡献。课程模块可以停用；其他模块可以继续向该槽贡献内容。分页时计数明确显示加载范围，业务操作继续执行已有审核流程。

## 公共控件与导航

主操作使用填充按钮，次操作使用描边按钮，辅助操作使用文字按钮；筛选项用强调色表示选中。按钮执行事件期间保持声明的外观，通过回调保护避免重复执行。

底部导航参考 [FlClash v0.8.99](https://github.com/chen08209/FlClash/releases/tag/v0.8.99) 的悬浮胶囊结构，沿用序点配色和线性图标。主导航胶囊按入口数量收紧，右侧“更多”独立为圆形按钮；默认高度 62，标签 11，随系统大字体增加高度。选中背景可抬出胶囊轮廓，按压时增加 28 的宽高，内容随之放大；运动速度决定横向拉伸与纵向压缩。主胶囊与“更多”圆钮按压时最多增加 16 的整体尺寸，圆钮还可跟随拖动产生阻尼形变。主胶囊拖过边缘时轻微被拉动，松手后以弹簧自动回位。拖动采用连续追踪弹簧，松手时保留速度并吸附到入口，快速甩动最多向相邻入口延伸一格；取消和纵向离开恢复原选择。按下和拖动仅预览，松手后切换一次页面；点击当前入口仍触发编辑预览。缩放和位移只改变绘制，底栏报告高度和页面留白稳定；键盘与辅助功能可直接激活入口。高对比使用不透明表面，减少动画关闭位移和缩放动画。快捷输入有独立表面，位于导航上方。

日程日期标题和日期条共享 180 毫秒节奏；日期项按民用日期保留状态，快速切换继续当前过渡，只展示最近的离场标题，无障碍始终读取当前日期。高对比的日期选中色立即切换，普通过渡根据已绘制背景选择更易辨认的前景。快速添加使用 220 毫秒的高度与透明度过渡，平常刷新不重播；收起立即退出焦点、关闭点击及无障碍遍历，结束后输入离屏但保留草稿，展开不主动抢键盘。宿主减少动画设置直接显示最终状态。 大字体窄屏的日期条按字号扩大单项并横向滚动，日期变更将选中日置于可见区域，普通计数刷新保留手动滚动；课程时间移到卡片上方，正文使用全宽。任务完成／重新打开只在审核通过、提交成功后显示顶部成功提示；取消和失败不展示成功。

日程任务列表按稳定 ID 保留同一日期下已有行的 Element 和控件状态。提交成功后从查询结果消失的已完成任务使用 220 毫秒渐隐与高度收拢，退出开始即撤下点击、焦点及无障碍遍历；历史日期仍保留的已完成任务直接更新勾选。快速添加提交成功后，只给真正新增的任务一次 900 毫秒背景高亮。普通刷新、加载更多、外部删除、日期或项目切换不会播放完成退出，也不重复整表入场；连续操作保留已有退出的截止时间。减少动画直接更新最终列表并跳过高亮。独立根列表始终使用惰性视口和 key 到索引的匹配，内联贡献保留自然高度；这是视觉状态协调，数据查询、审核和提交仍遵循原模块协议。

工作区切换由入口选择触发，按入口顺序和文字方向进行 360 毫秒的左右滑入与滑出，顶栏与正文同步、底栏保持固定。页面内的横向手势由各模块处理，课表周切换等操作可正常使用。快速返回复用仍在过渡中的页面，旧页面停止接收触摸与无障碍焦点；减少动画立即显示目标页面。

底栏继续通过 `ui.chrome.bottomNav@1` 调用，保留用户配置的入口顺序、更多入口、快捷输入和界面包覆盖。布局编辑器复用真实底栏，拖动选择只操作编辑目标，不打开业务页面。实际高度持续报告给宿主，用于列表底部留白与课表收缩补偿。新日程控件可通过公共 UI 契约被其他模块调用或由 UI 包覆盖。

## 其他页面与实现选择

课表详情和设置、课程导入、AI 会话、UI 示例分类及模块贡献沿用分区标题、自然列表和轻量控件。真正的卡片、时间网格及控件示例保留各自的结构；长内容用圆角折叠区显示。原生设置与模块界面继续使用相同主题。

业务模块负责数据和动作，公共 UI 契约负责选择呈现。原生页面、条目、按钮、输入、反馈和图标也接入公共契约；其中输入控件和滚动视口保留原生所有者与必达槽位。默认实现来自宿主的 `app.ui.default` 提供者，选定 UI 包可以替换对应呈现，无需改动业务模块。恢复和审核使用宿主默认实现，普通外观设置接受选定 UI 包。

圆润线性图标使用自绘矢量路径，并通过 `ui.icon@1` 在多个场景复用，名称与调用方式见 [图标规范](ICON_SYSTEM.md)。

课表顶栏根据手指滑动距离连续上移，底部导航同步收缩；松手后保留当前进度。到顶下拉时可拉开顶部空隙，上滑先消除空隙，再收缩顶栏。惯性滚动、边缘回弹和程序跳转不改变顶栏进度。可见区域增加的空间补在最后一行之后，保持连续手势中的滚动位置与方向；窗口、键盘和课表几何变化重新计算边界。
