# 任务规划连续日期与紧凑布局验收

日期：2026-10-20。以用户确认的连续日期时间轴效果图为结构和视觉基准；方案见[连续日期与紧凑布局](../design/PLANNER_UX_REDESIGN.md#连续日期与紧凑布局2026-10-20)。

## 实施范围

- 单行紧凑顶栏：20字号标题、原生调整开关、普通加号与可信页面菜单。调整仍由宿主控制，保留确认、撤销及失活租约保护；独立页面保留原生调整入口。
- 日期栏仅显示可见日期及跳转入口，今天离开视口后显示“回到今天”。返回按钮与日期按钮使用相同点击区高度，避免出现时向下推移表头。
- 默认昨天／今天／明天三列，支持连续浏览过去和未来，周末、跨月与跨年不截断。附近21天只是数据预加载窗口，不扩大自动安排范围。
- 待安排默认单行横向任务条；展开为浮层，不改变网格原点，拖动时隐藏、结束后收起。范围外安排收为日期栏内的查看图标，只提示当前可见日期，不额外占一整行。
- 星期与日期同一行；今天列及当前时刻线使用规划时区。数据窗口更新、任务放大返回、时间轴缩放均保留相应浏览锚点。
- 真实页面使用现有课程、待安排任务及导航配置，不为复现效果图的示例文案修改业务数据。

宿主API升至1.35.0，任务规划模块1.6.0要求`hostApi:^1.35.0`，避免旧客户端安装后缺少连续日期或顶栏能力。无新增模块权限，无数据迁移。

## 实际页面验收

设备为已有的`emulator-5554`，保持1080×2400屏幕设置。通过真实触摸及界面节点检查：

1. 默认显示10月19／20／21日，今天居中；调整、加号、页面菜单均在同一顶栏，没有常驻五天按钮、分页箭头或范围进度条。
2. 调整开关实际切换后回到关闭，待安排浮层可以展开和收起；展开不推移网格，仍保留拖拽入口。
3. 横向浏览未来、过去时出现“回到今天”。默认、未来、过去各状态的日期表头均为物理像素`y=423–507`，返回按钮出现时网格不再下移。
4. 切到课表再返回，仍显示先前浏览的10月21–23日；重启应用并重新打开任务规划后仍恢复该日期。
5. 连续滑动至11月10–12日，超过初始预加载窗口，日期继续前进；返回今天后向过去滑动可查看10月17–19日。
6. 日期跳转弹窗可正常打开并取消；待安排任务长按后移出表格取消，没有提交任务变更，待安排数量仍为3，底部导航恢复。
7. 验收结束返回10月19–21日，快速调整关闭，浮层关闭；再次核对设备APK摘要，与最终构建一致。
