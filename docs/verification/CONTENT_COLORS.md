# 课表与任务规划自动配色

日期：2026-10-19。

课表沿用暖白画布和圆角网格，课程按稳定课程 ID 从连续 HSL 色域派生颜色。任务按稳定任务 ID 派生颜色，候选、排期与拖动预览共享身份。颜色不依赖列表顺序、当前周次或随机数，也不调用图片生成服务。颜色可能接近，名称、时间、课程图标、只读纹理与固定时间图标仍保留。

课程统一在 occurrence 查询层派生颜色，今日课程和规划占用 feed 传递同一颜色。课表网格与规划看板使用相同的表面混色和文字对比度处理，明暗主题标题对比度测试不低于 4.5。课程占用显示斜纹，任务使用实色表面；选中时保留颜色类别并增加边框和高亮。

课程编辑支持留空自动配色，明确填写时保存 `colorMode: custom`。没有模式标记的旧默认 `#486DA4` 按自动色处理，其他有效旧颜色保留；历史上主动选择了该默认蓝、但没有来源标记的记录无法与旧默认区分，可在编辑器重新明确设置。新外部导入保留来源颜色，备份保留原模式。实体首次匹配忽略配色模式，导入合并基线仍完整保留；跨来源导入相同课程不会因为新增模式标记重复创建。读取不批量修改课程记录。
