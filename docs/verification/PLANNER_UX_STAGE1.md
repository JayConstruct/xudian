# 任务规划重构：第一阶段实施记录

后续：部分下列待办已在 [第二阶段](PLANNER_UX_STAGE2.md) 完成；本文件保留第一阶段验收范围。

日期：2026-10-15。依据 [任务规划交互细化](../design/PLANNER_UX_REDESIGN.md)。本轮开始实施交互原型与核心数据链路，不代表整份方案完成。

## 本轮实现

- 宿主 API 1.24.0；任务源码模块 1.5.0；规划源码模块 1.1.0。规划模块要求任务模块至少 1.5.0。
- 普通新增以简称为唯一必填业务字段，描述展开、截止日期可选、具体时间按需展开；手机底部面板、宽屏居中弹窗。同面板耗时子页保留草稿，保存后关闭并返回规划，不自动排程。
- 描述贯通真实任务创建、更新、查询、审核和撤销。当前截止使用 `dueDate/dueAt/dueTimezone`，创建固化 `initialDeadline`，调整记录 `deadlineHistory`；恢复初始截止也是一次新操作。只编辑描述不会改变截止精度。旧数据首次修改截止时保留旧值作为初始基准。
- 默认五天图形页，上部两行候选，下部日期与时间表格。最小列宽允许横向浏览；真实占用带与任务块命中高度分开；跨午夜各分段使用同一任务 ID；课程显示来源只读。密集任务通过选择清单避免极窄命中。
- 长按发起拖动，15分钟吸附，停留后进入1分钟细调；空白区域用于浏览。拖动发出移动／交换／插入意图，业务服务负责校验。详情提供精确起止输入。
- 移动、跨日、跨午夜和不等时长交换服务先计算全量结果，检查占用、固定和当前截止，提交前再次检查预览依据。交换保留各自时长；超截止汇总确认且不改截止。
- 无截止真实任务保留待安排，只有显式选择才进入自动排程。内部规划期限不会变成用户截止。“仅有截止”只筛选候选，所有已有安排继续显示和参与占用校验。
- 单一 `locked` 状态保护开始、结束和时长，规划实例入口同步此状态，旧跳过／取消入口也不能删除固定占用。
- 创建、任务编辑、移动、交换、既有排程采用持久操作记录与整体撤销。最近50条保留详细撤销快照；界面使用摘要查询，撤销时检查任务与关联实例是否发生后续变化或完成。
- 旧持续规则与可用时段设置入口保留，供原有功能继续使用。

## 验证

自动化覆盖任务描述与截止的 SQLite 关闭重开、审核与通用撤销、无截止显式选择、跨午夜、交换时长与固定保护、课程占用和过时预览原子拒绝、跨时区日期截止、最近50条操作历史，以及快速新增草稿、取消审核、候选筛选与安排独立、截止恢复和精度保持。

界面覆盖窄屏、大字号、深浅主题、空白滚动、候选选择身份、长按移动／细调、真实占用高度、密集任务选择及宽屏居中弹窗导航。Widget 测试不代表真机帧率。

已通过：25项 Python 规划引擎测试；10项新增规划服务测试；10项图形组件测试；20项任务模型、排程和AI撤销测试（文件SQLite持久化完善后7项模型测试另复测通过）；原宿主组件5项回归；规划、面板、审核相关42项组合回归。新增居中面板和截止精度测试所在最终24项集成回归全部通过。`flutter analyze --no-pub`、仓库边界检查、架构检查、`git diff --check` 和本地模块打包通过。

## 明确保留的后续工作

- 插入顺延依赖尚未确定的可安排时段、搜索天数与任务数量上限；本轮明确拒绝插入应用，不擅设缺省策略。原型六条验收流程中的“绕过课程顺延”尚未完成。
- 交换的两处图形预览、连锁位移实时预览、边缘自动滚动、占用带末端拖动缩放、按可见时段虚拟化和真机性能验证仍未完成。已有 `previewBlocks` 展示契约，尚未接通完整服务驱动的拖动预览。
- 规则分类搜索／完整逐级配置、有限生成器与批次编辑、持续规则新语义、分次执行、完整草稿恢复、完成／删除／取消安排交互继续后续阶段。当前新增规则子页仅提供耗时。
- 每日显示起止设置、跨午夜显示日期归属、全天入口仍待设计；组件具备显示范围参数，当前业务页按自然日展示。
- 图形操作仍经过宿主已有 `ui.review` 审核，尚未实现设计中“合法拖动直接应用”的最终体验；需与宿主现有数据审核政策共同设计。
- 外部课程只读；其他外部来源的可写权限与原子回写尚未接入。AI模型、调用、权限与自定义规则不在本轮范围。
- 历史详细快照最近50条以外不再可撤销；任务自身截止变更历史仍嵌入任务记录，未做大规模分页。

本轮仅修改源码并构建本地候选模块，不发布、不更新预装资源、不安装设备；实际使用需配套新宿主和新任务／规划模块。既有发布包保持不可变。
