## 已实现

- 拖动到图形区边缘时自动横向／纵向滚动。滚动位移与手指速度分离；细调状态保持稳定。结束、取消、离开视图和销毁组件时停止滚动。
- 占用带末端提供时长调整手柄，原开始由服务直接读取已保存时刻，避免图形分钟精度改写开始；跨午夜仍是单一任务、单次操作。固定和只读块不显示手柄；详情仍可精确修改起止。
- 交换时先显示保留双方各自时长的两处几何预览，再展示只读服务返回的合法性结果。释放时不使用已经离开的旧交换目标。
- 拖动位置停留180毫秒后调用轻量 query，显示最新预览和冲突。组件只采纳当前拖动、当前视图的最新结果，原始图形作为稳定子树，提示与预览局部更新。页面桥接只允许 query，保持宿主身份、权限、输入输出校验；最终提交继续重新校验和审核。
- 看板只对与显示日期相交的精确安排转换时间，使用最多256个时刻的批量转换；返回轻量字段，不把描述和完整截止历史复制到任务块。实时预览按任务标识查询关联实例，避免读取整批实例历史。
- 手动忙碌时段显示为只读占用；课程标识加来源前缀避免和任务重名。所有占用继续参与最终冲突检查。
- 详情与拖动携带最初读取的任务版本依据；同一毫秒连续修改或时钟回拨时，实际任务变更的 `updatedAt` 仍递增。没有变化的编辑不写任务、不占操作历史。已完成再重开也会使之前的快照失效。
- 最近50条详细撤销记录之外，另存紧凑的幂等凭证；旧操作被淘汰、应用重启后，以相同键重试不会重复创建任务或重新移动。旧批次在淘汰或首次重试时迁移凭证。
- 每次打开新增／详情面板使用独立表单会话，成功保存结果清理字段，避免旧表单覆盖最新数据。未提交的同一面板内切换保留草稿。
- 详情只提交实际改动字段。固定旧任务的预计时长为空时，修改描述不会隐式填默认时长；已安排任务的时长通过真实起止调整。精确截止在详情／拖动摘要中按其时区显示。审核取消后保留调整意图，可重试或放弃。

## 验证范围

服务测试包含：130项可见安排加200项隐藏安排只调用两次 `clock.toLocalMany`、零次单项转换；轻量看板输出不含描述／截止历史；相同毫秒的旧版本拒绝；预览不写入；历史淘汰超过50次及重启后的幂等重试；无变化不写历史；课程与手动占用的显示和冲突。

组件覆盖长按跨日、边缘双轴滚动、停留细调、末端拉伸、跨午夜、固定／只读保护、交换两处位置、旧目标释放保护、异步预览先后返回、取消和页面销毁、窄屏／大字号与密集任务。页面测试覆盖旧详情拒绝覆盖、取消后重试、独立会话、固定空耗时任务编辑、截止时区显示与真实只读预览桥接。

本轮通过：20项看板组件测试、18项规划服务测试、12项规划页面与桥接测试、27项既有任务命令／编辑／快照／规划回归；任务模型与撤销相关四文件32项回归通过；25项 Python 引擎测试通过。`flutter analyze --no-pub`、仓库边界检查、架构检查、`git diff --check` 与本地候选模块打包通过。各组合存在重叠，不累加为独立测试总数。Widget 和查询调用次数测试不等同于真机帧率验收。

## 后续边界

- 插入顺延仍未实施：可安排时段、搜索天数和任务数量上限尚待确认，不能把本轮交换／移动预览当成连锁顺延。
- 含秒起止导致非整数分钟的末端调整会明确拒绝，不会静默取整或改写开始。
- 未完成可见时段虚拟化、大规模候选分页及真机拖动帧率测试；看板数据仍需要读取任务和规则以构建候选，已优化桥接和输出，不声称全链路已按可见区加载。
- 有限生成器、持续规则新语义、完整规则分类、跨午夜显示区间归属、完整关闭后的草稿恢复和外部可写来源继续后续阶段。
- 合法落下仍经过现有宿主审核，未实现免审核直接应用。AI接入不在本轮范围。
- 幂等凭证长期保留请求摘要；未制定自动清理策略。`task.restore` 保留原有业务快照恢复语义，本轮未变更旧撤销契约。

只构建本地候选，不更新预装资源、不安装设备、不发布。
