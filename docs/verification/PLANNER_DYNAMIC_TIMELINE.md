# 任务规划动态日期窗口验收

日期：2026-10-20。延续已确认的紧凑布局，仅调整日期浏览、缓存和加载链路。宿主API为1.36.0，任务规划模块为1.6.1，无新增权限及业务数据迁移。本轮未提交或公开发布。

本记录对应动态窗口第一轮构建171。后续用户反馈的跟手问题已另行复现并修复，最新构建172及逐帧／实际按住手势验收见[横向拖动跟手修复](PLANNER_SCROLL_FOLLOW.md)。

## 实施范围

- 缓存内横向浏览只移动原生表格和表头，不调用页面处理器，不重新生成整页，不触发全局加载状态。
- 浏览位置即时写入页面状态，300毫秒合并保存界面偏好；业务操作、页面失活、应用进入后台和销毁前刷新待保存位置。静默保存仍执行模块身份、JSON大小和配额检查，记录偏好修订，但不触发本页刷新。
- 循环复用63天的物理列范围，日期本身不循环。仅构建附近的日期表头与可见任务块，最多缓存84天数据；接近缓存边缘时后台读取21天，窗口在滚动停止后保持绝对日期与列内偏移重定位。
- 后台查询使用同一模块、同一页面处理器和只读调用。回复只补充日期和任务块，不替换页面状态、顶栏、输入草稿或控制器；业务数据、模块实例、页面上下文或请求代次变化后丢弃旧回复。无缓存的列显示局部占位及失败重试，不拦截其他日期的滚动。
- 后台补数保持当前纵向显示时段和阅读位置，超出显示时段的安排仍可由日期栏入口查看。拖放预览、提交、快速调整授权、任务版本校验及撤销保持原协议。
- 表头改为惰性构建，表头与表格保持同步。横滑保留起始移动距离，降低短快划门槛，并提供较轻的惯性与四分之一列慢划吸附；竖向浏览和长按任务拖动保留。
- 未启用新timeline契约的旧模块保留事件式加载路径。

接口说明见[模块SDK](../MODULE_SDK.md#api-136-动态日期窗口)。

## 实际页面验收

使用现有`emulator-5554`，保持1080×2400与原系统密度；未卸载、清除数据或擦除模拟器。

1. 表格正文、日期表头、略斜正文手势分别向左和向右短划，6次均正确切换一天。每次移动130物理像素、持续160毫秒，斜划增加25物理像素纵向位移；表头几何保持不变。
2. 默认显示昨天／今天／明天；原生调整开关可切换并恢复关闭，待安排浮层展开不推移网格，收起后可以继续浏览。
3. 浏览未来后切到课表再返回，以及重启应用后重新打开任务规划，均恢复先前日期。
4. 连续浏览至11月10–12日，越过初始21天数据窗口及物理窗口的循环阈值，日期继续正确前进；向过去可查看周末，再返回今天。
5. 默认、过去、未来及循环后日期表头均保持物理坐标`y=423–507`，返回今天按钮出现不增加高度。日期跳转弹窗可打开和取消，任务长按移出表格取消不提交业务变更。
6. 验收结束返回今天，调整关闭、浮层关闭；再次读取已安装APK摘要，与构建产物一致。
