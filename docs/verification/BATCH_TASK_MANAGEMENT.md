# 批量任务管理子界面验收

日期：2026-11-03。按用户选定的批量管理 v02 设计图实现，保留现有 Flutter/Dart 宿主与 JavaScript/QuickJS 模块边界；本轮只覆盖新增管理子界面及相关通用组件，不代表全部规划页面重设计完成。

## 实现范围

任务规划菜单新增“批量任务”，进入完整子路由。列表提供搜索、全部／进行中／已暂停／已结束筛选、规则与真实数量摘要，以及补齐问题入口；详情展示规则、统计、待执行／完成／取消页签和生成实例。采用当前暖灰画布、白色圆角卡片、靛蓝操作、共享矢量图标、状态徽标和固定底栏。

新建复用批量创建预览与真实审核，批量专用草稿不覆盖普通新建草稿。暂停、恢复、结束保留已生成任务；规则修改先预览，仅影响后续生成；多选取消记录真实取消状态并支持既有撤销流程。单次任务详情在管理路由内复用，操作成功返回原批次，保留筛选和位置。长标题摘要限制行数并保留完整无障碍标签，日期、时段和次数列保持可读。

业务页面、文案、字段及服务在 app.planner；宿主仅扩展通用图标、徽标、卡片、文字行数、搜索／页签、弹性布局、固定底栏和紧凑详情顶栏。模块声明最低宿主 API 为 1.45.0。

## 实际页面与操作

- 菜单打开及关闭、列表返回／重开、搜索空结果及清空、各状态筛选通过；新建批量页返回／再次打开仍直接进入批量预览流程。
- 使用唯一 BatchAcceptance 标记创建真实批次，提交前查看实际变更。创建在首轮候选模块完成，最终版本另有页面与创建集成测试及新建返回／重开实机检查，不把早期截图作为最终版本验证。
- 最终版本详情显示四行生成实例；长标题省略，日期、时段、次数和操作按钮均可见。单次完成后回原批次，待执行6→5、已完成0→1；重新打开同一次任务后恢复6／0及原安排。
- 暂停、列表暂停态、重开、恢复通过；既有实例日期与时段保持。规则预览取消不写入，保存35分钟后已有6次仍保持原30分钟安排。
- 多选全选6项，取消审核后保留选择；再次确认后待执行0／已取消6。仅操作本轮标记批次，随后结束批次，保留验收历史，无活动验收任务。
- App进程冷启动后重新进入管理页通过，结束后的历史状态仍保留。
