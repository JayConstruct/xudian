# 批量任务优先时间点

2026-11-03，规划模块1.12.0，最低宿主API仍为1.45.0。

新建批量任务的“多次任务”页及规则页支持设置可选优先时间点；批次“编辑规则”支持编辑和清空，详情和变更预览显示该配置。草稿和模板保留优先时间。

优先时间是当天开始时间的偏好：先尝试精确分钟（例如21:03），冲突时按离该点最近的顺序尝试允许时段与实际可用时段内的5分钟候选，同距选择较早时刻。任务时长必须完整落入允许时段，仍遵守缓冲、课程／任务占用和当前分钟限制；原日期与重复间隔规则保持。手动位置和锁定优先；修改仅影响尚未生成的任务，清空恢复原算法。

本轮仅改模块JavaScript、测试及文档，不改宿主运行代码，使用scripts/update-emulator.sh --modules-only --module app.planner；实际更新及设备结果以本机dist/verification/preferred-time/verification.json为准。本轮实际设备检查已通过，见下方范围。

测试包括精确非5分钟点、真实占用回退、等距选择、多个可用片段、例外时段、越界及耗时校验、手动／锁定优先、旧数据行为、创建存储与查询往返、规则编辑及清空、滚动补齐和旧实例保留。页面测试还覆盖新建草稿返回重开、规则预览及清除回显。
