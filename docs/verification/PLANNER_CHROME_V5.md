# 任务规划第五版界面实施

日期：2026-10-17开始实施，验收跨至2026-10-18。依据用户确认的第五版效果图及 [界面方案](../design/PLANNER_UX_REDESIGN.md#表格外界面与分级菜单2026-10-17)。

本轮将新建收为带读屏名称的加号按钮，操作历史移入更多菜单；视图与显示、待安排筛选采用同一锚定浮层内逐级进入和返回。模块动作与宿主设置入口分开管理，页面失活后旧贡献不再分发事件。窄屏放不下的加号会回到菜单内，保留添加入口。

候选区域保持两行、手机两列与区域内横向浏览，折叠保留位置；快速调整沿用现有确认和撤销规则。移除表格上重复的五天按钮、时钟与候选筛选按钮，日期栏保留日期、今天及前后翻页。范围条按当前窗口逐段显示可见日期，默认五天仍可横向浏览。

视图子菜单提供1／3／5／7天、自定义1至28天、每日显示时段及五级时间轴缩放。缩放单独持久保存到模块界面偏好，普通缩放保留顶端浏览时刻和横向偏移；专用短时段放大继续独立使用。所有这些选项只改变视图，任务和截止不变。

源码版本：宿主API1.30.0，任务规划模块1.5.0（最低宿主^1.30.0）。新增公开菜单协议及版本门槛见 [模块SDK](../MODULE_SDK.md#api-130-的图标按钮与分级菜单)。

菜单打开时由原生持有活动租约，仅允许当前页面继续发布菜单标签和选择状态；没有放宽页面写入、模块权限或失活保护。菜单事件按点击顺序等待页面空闲，包含界面偏好引起的后台刷新，避免连续缩放被通用“只保留最后意图”槽覆盖。系统返回逐级回到上层，点击遮罩直接关闭整张菜单。
