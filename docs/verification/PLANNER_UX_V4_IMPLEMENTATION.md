# 任务规划第四版界面实施验收

历史范围：2026-10-16～17，后续规则以 [规划交互](../design/PLANNER_UX_REDESIGN.md) 为准。初始 v4 的五天／两行候选、15 分钟吸附与停留精调已被后续交互替代，不能作为当前默认值。视觉参考为 [第四版图](../design/planner-ux-redesign-v4.png)。

## 初始实施与验证

图形看板替代旧首页，新增／详情／规则采用渐进面板；按真实起止绘制占用，支持选中空档、短任务选择和单日放大。放大不改写任务、时长、选中与数据版本，课程继续作为真实只读占用。虚拟列表具有独立 scope 和稳定键，保存按钮全宽，内部返回保留草稿。

11 个相关测试文件共 134 项通过，静态分析、架构和仓库检查通过。覆盖 320 宽大字号／浅深色、1100 宽布局、672 任务／28 天、短任务与边缘拖动、真实提交后撤销、过时预览和冲突保护。

复用 `Medium_Phone_API_37.0`，按 `scripts/update-emulator.sh --force --module app.planner` 覆盖安装，保留应用和模块数据。初始构建 123／versionCode 4123，规划 1.4.1／宿主 API 1.26；产物与设备摘要一致：

## 保留边界

本记录不证明整份规划方案完成。初始 v4 未实现新的有限生成器、持续规则或规划 AI，插入顺延未擅自确定可安排时段和搜索上限；后续能力见 [任务新建](../design/TASK_CREATION.md) 和 [发布验收](../VERIFICATION.md)。普通确认与快速模式始终核验同一冻结计划、权限、占用和任务版本，不接受脚本声称跳过审核。

设备操作覆盖的是当时版本和已列场景，不代表 ARM 真机、Windows 或真实 FPS 全部通过。录屏采样、瞬时 Toast 的 XML 与实际屏幕可能不同步，最终以实际屏幕及即时操作验证；额外测试修改通过撤销恢复，保留用户此前其他安排。
