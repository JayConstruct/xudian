# 任务规划第四版界面实施验收

日期：2026-10-16。设计依据：[任务规划重设计](../design/PLANNER_UX_REDESIGN.md)，视觉参考：[第四版视觉稿](../design/planner-ux-redesign-v4.png)。原始草稿与提示词现归档于本机 `dist/design/imagegen/`。

## 实施范围

- 移除旧首页渲染代码，以单一图形看板作为任务规划首页；新增、详情、规则与设置使用独立渐进面板。顶部新建、操作历史沿用宿主组件，并保留受保护菜单入口。
- 待安排任务保持简称与情境摘要两行；普通截止使用主题灰靛色，无截止显示预计耗时，逾期使用明确状态文字。截止筛选只筛选候选，不隐藏已占用时段。
- 时间块在真实占用带的上、下内边缘显示起止。按列宽、缩放与系统字号逐级减少内容，短任务保留真实时长细条、连接线和外置标签，密集任务通过选择列表进入单日时段放大。
- 选中显示前后空档和简洁详情，提供精确编辑时间及完整详情入口；空档依据全部实际占用并集计算，包含只读课程及固定任务。跨日结束日期与连续标识保持明确。
- 放大只改变显示几何，保留任务起止、时长、选中与数据版本。保留15分钟吸附、停留后1分钟细调、调整时长、不等时长交换、最新版本校验与持久化整次撤销。
- 拖动提示按实际尺寸限制在屏幕安全区域内，实际落点仍由原始指针决定。长任务标题只有滚动被裁切后才驻留，避免重复。
- 历史、候选选择及自动安排预览采用具有独立 scope 与稳定唯一 key 的虚拟列表。保存操作在底部使用全宽按钮；内部返回保留草稿，关闭面板独立于内部返回。

本次是第一阶段界面与核心交互实施。有限生成器、持续规则与AI的新能力未纳入本次实现。插入后自动顺延仍提示未确定的可安排时段和搜索上限，不自行选取默认值；原有规则、模板与自动安排能力保留。
