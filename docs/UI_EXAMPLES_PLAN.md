# UI 示例页与共用组件修改方案

状态：首批已实现，包含 17 个生产脚本示例；验证结果见文末。依据：[GitHub 调研](UI_EXAMPLES_RESEARCH.md)及当前生产脚本、公共 UI 契约、页面模板、宿主表单和滚动实现。

## 目标与范围

本轮交付一个容易查找、可真实交互、可观察不同状态的 UI 示例页，同时把日期等控件补齐为其他模块可调用的公共能力。沿用现有 Material 3、连续圆角、主题和 UI 包机制。

生产实现从 `packages/modules/app.ui.examples` 与 `client/lib/core/module_host` 入手。旧架构的原生示例页不承担本轮生产入口实现。

首批交付：页面分类与筛选、响应式示例卡片、局部重置，以及日期、时间、日期时间、日期范围、真实多选、数字输入、搜索输入。复用已有按钮、单选、开关、滑块、任务卡片、状态反馈及弹窗示例。

后续扩展：菜单、提示气泡、分段选择、徽标、折叠区等常用控件。复杂表格、树和拖拽暂列后续需求。

## 页面结构

应用现有顶栏显示“UI 示例”并保留返回入口。页面不再重复输出大标题；顶部工具区提供组件搜索、分类、匹配数量及“重置全部”。“页面槽位与跨模块嵌套”归入布局与组合分类。

建议分类：全部、基础操作、输入与表单、选择控件、日期与时间、状态反馈、布局与组合。

| 区域 | 手机／窄屏 | 桌面／宽屏 |
| --- | --- | --- |
| 搜索与操作 | 搜索独占一行，数量与重置放下一行 | 搜索、数量与重置可同排 |
| 分类导航 | 使用有明确选中态的 Chip，横向滚动 | 同一套 Chip，空间足够时完整显示 |
| 示例内容 | 单列，控件按卡片可用宽度展开 | 满足控件最小宽度时两列 |
| 示例卡片 | 内容决定高度 | 内容决定高度，不强制等高 |
| 滚动 | 工具区固定，卡片区一个纵向滚动容器 | 同样共用一个滚动容器 |

列数按内容区宽度而非设备类型决定。建议初始规则：卡片区可用宽度至少 680 逻辑像素时两列，列间距 16；文字缩放超过默认时相应提高双列阈值。该值在实际控件测试后调整，属于宿主设计常量，模块不传自由像素值。

沿用宿主现有宽度约束：详情页最大 760、工作区最大 1040。因此同一桌面窗口中的窄面板也可以保持单列。手机左右留白 16，宽屏最多 24；底部遵循 `WorkspaceContentInsets`。

复用 `ui.page.list@1` 的 `filters` 和 `items` 槽位：工具区放 filters，滚动卡片区放 items。宿主增加无内部滚动的响应式 grid 排列；保持 items 仅有一个滚动所有者。以默认 UI 和已有示例 UI 包分别验证高度约束。

## 示例卡片

每张卡片依次包含：

1. 组件名称、简短用途和“重置此项”。
2. 适用的状态选项：默认、已选、禁用、错误；具体组件不支持的状态不显示。
3. 真实交互控件。
4. 当前值或本地操作结果。
5. 可展开的“使用说明”：公共组件 ID、值格式、事件格式、最小调用示例。

技术说明默认收起。卡片状态只作用于演示控件；禁用示例时，卡片的状态选择和重置仍可用。反馈就近显示，避免所有操作共用一个 lastAction。

采用应用既有 ContentSurface 和主题层级，统一内边距与纵向间距。卡片不再套多层卡片，不强制固定高度；代码说明允许横向滚动，预览区域不设独立纵向滚动。

## 首批组件

| 组件 | 公共契约 | 首批行为 |
| --- | --- | --- |
| 日期 | `ui.dateInput@1` | 输入外壳、日历选择、手动输入、清除、日期边界与错误提示 |
| 时间 | `ui.timeInput@1` | 统一外壳，保留原生 24 小时时间选择和现有事件行为 |
| 日期时间 | `ui.dateTimeInput@1` | 先选日期再选时间，全部确认后回传；任一步取消均保留原值 |
| 日期范围 | 新增 `ui.dateRangeInput@1` | 原生范围选择，起止日及区间展示、清除、边界校验 |
| 多项选择 | `ui.multiSelect@1` | 使用 FilterChip 展示少量选项，选中集合整体回传 |
| 数字输入 | `ui.numberInput@1` | 数字键盘、整数／小数配置、范围校验；编辑时保留原文 |
| 搜索输入 | `ui.input@1` 的搜索模式 | 搜索图标、清除、输入防抖，复用文本输入生命周期 |

搜索首先支持组件名称、简短用途和静态契约 ID，不搜索演示输入值。搜索在当前分类内执行；清空搜索不清空示例数据。零结果显示“没有匹配的组件”并提供“清除搜索／查看全部”。

日期示例安排六种可复现情形：未选择、已有值、禁用、非法手动输入、允许日期边界、取消与清除。日期范围另外展示起止关系；多选展示空选、已选和禁用。

## 日期值与事件契约

新的公共选择控件使用下列规范，显示文案和内部值分离：

| 类型 | 值 |
| --- | --- |
| 日期 | `"2026-10-08"` 或 null |
| 时间 | `"09:30"` 或 null |
| 日期时间 | `"2026-10-08T09:30"` 或 null，表示无时区的本地日期时间 |
| 日期范围 | `{start:"2026-10-08",end:"2026-10-10"}` 或 null，起止日均包含 |
| 多选 | 选项 value 数组；空选为 `[]` |

日期时间控件负责选择本地日期和时间；需要表示绝对时间点的业务模块另行声明时区并转换，控件不擅自加 Z 或转换 UTC。

所有新选择控件在确认或清除时先同步宿主 formValues，再转发调用方的 change 事件。取消不产生 change，清除回传 null。数字与搜索输入仍保留编辑原文，数字在有效校验／提交时解析，不能把非法文本静默变成 0。

推荐调用形式：

```javascript
ui.component('ui.dateInput@1', {
  key: 'demo.plannedDate',
  props: {
    label: '计划日',
    value: state.plannedDate ?? null,
    clearable: true,
    minDate: '2026-01-01',
    maxDate: '2027-12-31',
  },
  events: {change: {type: 'changeDemo', id: 'plannedDate'}},
})
```

事件回传 `{type:'changeDemo',id:'plannedDate',value:'2026-10-08'}`；清除时 value 为 null。该调用形式已由 API 1.7 支持。

## 宿主与脚本实现

### 公共层

在 `client/lib/core/ui/` 新增日期系列控件与响应式内容排列。日期控件集中处理显示、输入解析、选择器调用、清除、校验和键盘／焦点行为；脚本页面与宿主表单共用该实现。

现有 `timeInput` 的按钮语义、24 小时制和迟到结果防护必须保留。日期控件也检查页面会话、模块实例以及字段是否仍有效，防止切换分类、退出页面、更新或停用模块后的弹窗结果写回。

### 渲染与表单层

修改 `script_page.dart`：修正 dateInput／dateTimeInput／multiSelect 的公共组件映射，补齐 dateRangeInput、numberInput 和搜索模式。所有原生输入依然通过 control 槽位提供给 UI 包。

tabs 读取已有 selectedIndex 并显示选中态；没提供 selectedIndex 的旧节点继续保留原行为。现有 input/select 节点和事件字段维持兼容。

修改 `host_dialogs.dart`：为既有 date／datetime 文本输入增加选择入口，复用日期校验；保留手动输入、既有返回形态及已有 ISO 日期时间的兼容路径。新控件的 null 空值在旧对话框边界转换为旧协议的空字符串，避免无意改变已有模块表单结果。新增 time／dateRange 字段须同时补充宿主支持及文档。

修正 clearForms／replaceForms 对无 TextEditingController 的控件处理：比较提交时字段值与当前字段值，未继续编辑才允许替换。日期范围与多选须进行内容比较；不能用 controller 不存在作为允许覆盖的条件。

### 示例模块

将 `app.ui.examples/main.js` 拆成目录定义、示例构造和事件处理文件。每个示例具有稳定 id、category、title、description、默认值和支持的状态，方便增加新组件。

状态按示例 id 隔离，例如 `state.examples.plannedDate`。页面只使用本地模拟值，不增加数据／网络权限。保留已有页面、入口和组合槽位 ID。

## 状态与重置

- 切换分类、搜索和文字缩放保留示例输入。
- 分类有本次会话的滚动位置；主动搜索后展示匹配列表顶部，清空搜索恢复该分类位置。
- “重置此项”只重置对应值、演示状态、校验错误和本地结果。
- “重置全部”清空所有示例值和错误，但保留当前分类、搜索条件和浏览位置。
- 重置处理复用 replaceForms 的提交后编辑保护。快速连续输入不被脚本迟到响应覆盖。
- UI 包切换时保留输入控制器、焦点、选择范围和滚动位置。重复演示 key 不得出现。
- 演示状态仅保存在现有短期 pageSessions，不增加数据库存储。

## 兼容与版本

新增宿主能力建议发布为 API 1.7.0；示例包提高版本并声明 `hostApi: "^1.7.0"`，旧宿主明确拒绝新包。既有包的 ^1.0.0／^1.6.0 范围仍可使用新宿主。

公共组件继续 @1；新增 props 均为可选。现有契约的 requiredSlots 和必须保留的 events 不增加要求，避免使旧 UI 包失效。新增日期范围契约使用 control 槽位，缺少对应包样式时回退内置控件。模块格式、数据版本和数据库结构无需调整。

## 实施说明

分类栏改为横向滚动：320px、2 倍字号的测试发现换行分类会挤占卡片视口；单行 Chip 保留明确选中态，同时让正文保持可滚动。既有普通 tabs 默认仍可换行。

首批增加 ui.slider@1 公共槽位封装，使既有滑块也可通过公共组件调用。示例状态和详情说明属于脚本模块，宿主只提供通用排列、输入与展开能力。

日期范围弹窗按实际字体宽度调整日期标题，预留结束日期空间，并考虑从输入模式切回日历时的尺寸动画。保持原生日历、日期格式和文字缩放规则，避免窄屏和跨年日期造成横向溢出。
