# 课表

当前源码模块 `app.schedule` 为 **1.7.0**，最低宿主 API 为 **1.10.0**，数据版本为 1。课表作为独立 `.xmodule` 安装，不随当前客户端默认资源启用。更新方式见 [模拟器更新](EMULATOR_UPDATE.md) 或 [模块商店](MODULE_CATALOG.md)。

## 浏览与导航

- 中间教学周标题可点击，弹窗以纯数字圆角按钮网格选择；点击立即切换，取消保留当前周。列数适配宽度与字号，周数较多时滚动。
- 右上角统一页面菜单，提供切换课表、回到本周、今日课程和设置等操作，并合并顶部模块入口与宿主设置。
- 日期头固定，左侧节次固定，课程按连续网格显示；高亮使用课表时区的当前日期和时段。
- 非空周视图可随纵向滚动收起顶栏/手机导航，并通过宿主按钮恢复；横向操作不触发收起。末节课程可滚到悬浮导航上方查看和点击。
- 模块首次返回前预留顶栏区域，避免临时标题闪烁；顶栏与其他工作区使用统一高度，大字号同步适配。快速加载不显示进度条，超过 500ms 才显示，模态弹窗等待期间暂停。

## 显示设置

从页面菜单或课表设置进入显示调整悬浮面板。默认显示周一至周五；可开启“显示周六和周日”，五列与七列均分可用宽度，保持节次栏固定并适配屏幕。隐藏周末只影响显示，不删除课程，查询、今日课程和备份仍包含周末。

行高可以滑动调整，也可用 `−1` / `+1` 精细调整总高度；每节范围 48–160，默认 72。12 节默认总高度 912，范围 624–1968；日期栏保持 48。面板与课表独立滚动，打开/关闭面板不改变网格视口尺寸。

调整实时预览，点击“保存显示设置”并完成宿主审核后生效。关闭面板恢复已保存显示值，当前会话保留草稿；“恢复默认高度”只改高度草稿，“重新载入”丢弃草稿并重读保存值。保存会检查外部修改，避免覆盖其他页面改动。

`rowHeight` 和 `showWeekends` 按课表保存，重启保留并包含于 JSON 备份；旧课表省略字段时采用默认高度并隐藏周末。

## 课表配置与课程

课表设置按概览、课表配置、课程与调课、数据管理分组，提供学期、IANA 时区、作息、课程管理、调课、导入/备份及课表管理。第一周以民用日期的周一为基准，显示起始星期不改变课程日期语义。

新建课表默认 12 节、每节 45 分钟；已有课表不会随安装改写。作息可逐节编辑，拒绝重叠、跨午夜与删除被课程引用的节次，保存须审核。补足模板保留已有时段，仅追加末尾。

点击课程先显示详情，再编辑周期安排或做单次调课，支持取消、换地点/节次、跨周移动和临时课程；详情按当前数据重读。手机与宽屏使用适配面板。

## 导入与备份

拾光和学校适配器通过公开服务及 `importers` 槽位接入，流程见 [拾光导入](SHIGUANG_IMPORT.md)，服务协议见 [模块宿主](MODULE_HOST.md#课表与教务扩展)。导入先预览新增、修改、删除、冲突和警告；处理冲突后由课表确认并交给宿主审核，预览和取消不写入正式数据。

重复来源导入按上次来源、本地当前和新来源三方比较；局部或空结果不清空课表。JSON 备份不包含教务凭据/会话，新建导入会重分配本地实体 ID。自动刷新、提醒、拖动课程和跨设备同步仍待实现。
