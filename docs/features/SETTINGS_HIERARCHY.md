# 设置层级

当前生产宿主的设置采用分类首页，具体选项进入二级页。手机与电脑使用同一分类，桌面内容宽度限制为 760；布局编辑器保留宽屏双栏。

```text
设置
├─ 外观与交互
│  ├─ 外观主题 → 跟随系统 / 浅色 / 深色
│  ├─ 界面风格 → 全局风格 / 模块专属界面 / 恢复
│  └─ 触感反馈
├─ 布局与导航
│  ├─ 入口与位置
│  │  ├─ 编排入口 → 底部导航（电脑为侧栏导航）/ 右上角菜单 / 更多或全部入口
│  │  ├─ 入口目录
│  │  └─ 常用与隐藏入口
│  ├─ 页面编排 → 页面内容布局 / 高级编辑
│  └─ 本次草稿 → 预览结构 / 查看变更
├─ 模块与连接
│  ├─ 模块管理与恢复
│  ├─ 模块商店
│  ├─ 模块提供的设置（settingsSections 贡献）
│  └─ 模块专属设置（挂载到设置的内容页面）
├─ 更新设置 → 启动检查、应用与模块更新
├─ 导出所有配置 → 配置备份
├─ 辅助工具 → 显示与布局信息、界面标注模式
├─ 关于序点 → 实际安装版本 / 检查更新 / 本机数据说明 / 项目地址 / 模块仓库
└─ 常用入口（按当前屏幕布局的顺序展示）
```

首页顶部并列展示「外观与交互」和「布局与导航」，外观卡片显示当前主题。「应用与数据」收纳模块与连接、更新设置和导出所有配置，「支持与关于」收纳辅助工具和关于序点。发现更新或开启界面标注时，对应行显示状态。常用入口按布局配置排序，仅在有入口时出现。

宽屏内容居中，左栏是个性化和常用入口，右栏是应用与数据、支持与关于。窄屏或系统大字号时改为单栏，放不下的状态移至摘要下方。主题偏好读取失败时，外观入口仍可打开并重试。

外观页的主题和触感修改自动保存，保存期间禁用这些控件，失败保留已应用设置并提示重试。界面风格与布局继续使用显式保存的草稿；说明文字区分自动保存、预览与保存后应用。界面风格与恢复页面使用内置界面。系统减少动画对页面切换、日期和操作反馈的影响见[动画与手势](../ui/MOTION.md#宿主动效时长)。

“布局与导航”直接打开编辑器，避免只有一个选项的中间页。从设置进入时，根据 820px 分界默认选择手机或电脑配置，仍可手动切换。

在「编排入口」顶部选择底部导航（电脑为侧栏导航）、右上角菜单或更多。「可添加入口」可按名称、模块或入口标识搜索，结果标出当前位置。点「添加」或「移入」会将入口放到当前分区末尾。也可长按候选入口拖到预览中的具体位置，插入线标明松手后的落点。

长按预览中的图标或条目可排序，列表也可直接拖动行尾手柄。拖过分区标签会切换预览，在新分区的落点松手即可移入。拖到页底的移除区松手会隐藏该入口，可撤销或从候选列表重新添加。在其他区域松手会取消此次拖动。轻点已放置的入口可逐位移动、移除或进入位置与上下文设置。固定的「设置」及「更多」保留原位，超出导航直显上限的入口列在导航预览下方。

编排只修改所选屏幕配置的草稿，点「保存布局」后应用。「常用与隐藏入口」用于调整设置首页的快捷方式。各状态见[应用设置图稿](../../design/PAGES.md#应用设置)。

「更多」位于导航最左侧，集中展示工具入口、主导航溢出项与设置。右侧圆形按钮用于当前页面支持的 AI 功能。要调整「更多」，从**设置 → 布局与导航 → 编排入口 → 底部导航（电脑为侧栏导航）→ 显示选项**进入，切换「启用“更多”页面」或调整「主导航直显上限」，点「返回编排」后再点「保存布局」。手机与电脑配置独立保存。「更多」默认启用，读取缺少此选项的旧布局时也按启用处理。关闭后，工具及溢出入口仍可从右上角菜单的「全部入口」访问，菜单中的固定「设置」也始终可用。

子页面共用父页面的布局草稿，返回分类页及进入另一分类不会丢失未保存修改，也不会自动应用；从子页面保存后返回分类页，从首页保存后返回设置。预览不打开或构建业务页面。搜索、技术标识、诊断及失效配置保留在“高级编辑”；回到分类页时清空筛选，避免影响可视编辑中的排序。页面范围及宽屏检查器保留原有编辑能力。

模块的 `settingsSections` 贡献移到“模块与连接”下单独成组。挂载到设置的普通入口保留在首页常用入口；内容页面仅在模块分类显示一个入口，打开后完整显示，不再在首页重复内嵌固定高度页面。两种入口都遵循当前布局顺序，并把挂载上下文传给 `UiPageHost`。

关于页保留地址打开、复制、打开模块商店等操作；与“模块与连接”共用当前配置的模块目录。关闭业务模块后，设置分类及模块管理恢复路径仍然可用。

「更新设置」中的启动检查开关即时保存，手动检查 App 和模块各有独立入口。「检查更新」默认从 GitHub 查询正式 App Release，可开启并记住测试通道以接收测试版本。检查结果、更新说明与下载入口见[检查 App 更新](../INSTALLATION.md#检查-app-更新)。

入口为 `client/lib/core/module_host/host_settings_page.dart`。`features/settings/legacy_settings_page.dart` 为旧模块架构的兼容页面，不是生产壳层的设置入口。

验证覆盖设置分类的进入与返回、主题与交互偏好持久化、辅助工具状态摘要、320px 大字号、宽屏深色、当前设备布局默认选择、入口排序、内容页面只按需构建及上下文传递。既有宿主恢复、模块设置贡献、界面包、模块商店与课表壳层回归随新层级调整。

## 显示与布局诊断

入口：“设置 → 辅助工具 → 显示与布局信息”。实时读取当前 `FlutterView` 像素尺寸／像素比，以及根 `MediaQuery` 逻辑视口、安全区、键盘遮挡与实际字号样本（12、14、24）。页面容器及内容可用宽度单独记录；平台视图像素尺寸不等同于面板硬件分辨率，`TextScaler` 样本不假定线性倍率。

只有用户主动点击才复制指标 JSON。数据使用字段白名单，不含任务、输入草稿、账户或密钥；不截图、上传或修改系统／应用显示设置。窗口、键盘、安全区与像素比变化时更新，使用当前视图而非默认的首个视图。

Android 只读系统测量工具：

```bash
source scripts/dev-env.sh
python3 scripts/module_host/measure_android_display.py \
  --serial DEVICE_SERIAL \
  --output dist/verification/display/device-display.json
```

支持 `--adb-host` 与 `--adb-port`，默认沿用 `XUDIAN_ADB_HOST`／`XUDIAN_ADB_PORT`。工具只读取 `wm size/density`、字体设置、平台信息和目标应用的 Android 配置；保留原始尺寸与覆盖值，计算结果明确标为估算，Flutter 视图实测需从应用诊断页获取。不写系统设置、不采集其他应用配置或界面正文。

用实际逻辑视口、安全区和字号样本比较设备上的显示差异。剩余平台与显示场景见 [设备验收缺口](../PLATFORM_VERIFICATION.md#设备验收缺口)。
