# 新增「想法」模块

「想法」按需安装，默认从「更多 → 想法」进入。打开后就能写下一句话，点「记下」或按键盘提交即可保存，继续记录下一条。每条想法都可以在以后手动生成多个待安排任务或项目。

## 记录与回看

- 页面底部固定记录框，键盘展开时位于键盘上沿。上方时间线可滚动。按本地日期分组，最新记录在前，每条显示记录时刻和正文。保存成功后清空输入框，失败时保留原文。
- 提供「全部」「收藏」两个视图。长按条目可收藏、取消收藏、编辑或删除。编辑和收藏都保留原来的时间线位置，删除需确认。
- 已经生成过任务或项目的想法留在原位，使用浅色背景、实心节点和摘要，例如「已创建 · 2 个任务 · 1 个项目」；普通条目使用素底与空心节点。点开可查看每次创建的类型、当时填写的名称和创建时间。

- 全部记录支持按正文关键词跨日期搜索。点时间线的日期标题进入该日记录，可切换相邻日期，或通过月历直达指定日期。

## 从想法创建任务或项目

- 长按菜单提供「创建待安排任务」和「创建项目」。两种表单都展示想法原文供参考，名称框初始为空，由用户重新填写。
- 创建任务后进入任务规划的「待安排」区，计划时间和截止日期留空。创建项目后进入项目根目录。之后仍可从同一条想法再次创建，包括连续创建多个同类对象。
- 编辑或删除想法只作用于想法本身。已经创建的任务和项目独立保留。

## 模块实现与设计审核

- 独立 JavaScript 模块 `app.ideas` 从「更多 → 想法」进入。想法和创建记录由模块持久化，任务和项目复用 `app.tasks` 的现有创建服务。一次确认同时提交目标对象和创建记录，避免重复点击或失败重试产生重复对象。
- 已确认的 18 张图稿登记在[设计页面表](../../design/PAGES.md)。编辑弹窗在正文上方分别显示创建时间和上次保存正文的时间。收藏、创建任务和创建项目都保留原想法的创建时间与正文修改时间。

## 验收与交付

- 验证连续记录、空白输入、跨日排序、收藏筛选，以及编辑后的位置。用同一条想法创建两个任务和一个项目，核对目标列表与三条创建记录，并验证取消、重复点击和删除原想法后的结果。
- 模块包和版本索引登记在本地商店目录。模块 1.1.1 的紧凑时间线、空态插图、记录框和引用表单需要宿主 API 1.59。首次更新用 `scripts/update-emulator.sh --module app.ideas` 同步升级 APK 和模块。后续只修改模块时，兼容宿主可使用 `--modules-only`。
