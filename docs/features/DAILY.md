# 日程

点击顶栏日期打开月历，左右箭头切换前后日。浏览其他日期时，可从页面菜单回到今天。时间轴按开始时间混排课程与任务，在课程原位置标出正在上课或即将上课。待安排任务单独成组，宽屏时显示在右栏。点击课程查看详情，课程安排在 [课表](SCHEDULE.md) 中修改。

展开快速添加可为所选日期新增任务；收起后重开保留草稿。点击任务进入编辑，按页面提示保存，取消不提交本次修改。完成勾选后任务保留原时间位置与分组，以淡色、删除线和完成说明表示状态；再次操作可重新打开。已完成任务可关联到计划日、截止日或实际完成日，日期变化不等于重复创建任务。

需要为任务安排执行时段或查看安排历史时，打开[任务规划](TASK_PLANNING.md)。日程入口缺失时，在[模块管理](../INSTALLATION.md#从商店安装业务模块)查看模块的安装与启用状态。
