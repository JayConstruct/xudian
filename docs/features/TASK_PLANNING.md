# 任务规划

通过规划看板新建任务、安排执行时段和管理批次。按日期查看任务与课程见[日程](DAILY.md)。模块安装与启用步骤见[安装指南](../INSTALLATION.md)。

## 安排任务

进入任务规划，用加号新建任务；名称必填，描述、耗时和截止按需配置。普通任务可以没有截止，保存任务与安排执行时间是两个操作。

长按待安排任务拖入时间表，或移动已有任务、调整结束位置；也可在详情中精确编辑。时间块位置表示实际执行起止，截止是独立期限。课程和固定任务不能直接拖改，冲突或超截止时按提示处理；取消确认不写入。

普通调整会显示操作确认；开启“快速调整”后，符合条件的单任务调整直接保存，成功后提供撤销。多任务交换、超截止等仍需明确确认。最近提示只撤销最近一次实际调整，更早记录从操作历史查看；任务已有后续修改或完成时可能无法撤销。

日期栏可跳转和回今天，横向浏览连续日期。点击日期表头可查看当日任务。缩放、列数与每日显示时段只改变视图，不重排任务。

工作区的规划模块已移除“自动安排”菜单及对应的 AI 工具。拖动支持移动、交换和调整时长，按 5 分钟吸附；精确时间编辑支持任意分钟。批量任务仍按已确认的重复规则持续补齐。版本差异见[文档首页](../README.md)。

## 批量任务与持续规则

新建时区分单次与批量。选择规则后先查看预览及未安排原因，确认前不创建任务；修改规则与返回遵循页面上的应用／取消操作。模板可复用配置，删除模板不会删除已生成任务。

持续系列在启用且 App 运行或恢复时补齐后续实例，不重新安排旧任务，不承诺关闭 App 后继续常驻。批量创建的撤销会同时撤销其持续系列，避免再次生成。详细规则见 [新建与持续规划](TASK_CREATION.md)。

从任务规划右上角菜单进入“批量任务”，按批次搜索、筛选进行中／已暂停／已结束的系列。列表显示重复规则、完成与待执行数量及下次安排；有补齐问题时可进入详情查看原因，再修改规则或重新补齐。每个批次依实际系列归组，同名任务不会自动合并。

批次详情可查看待执行、已完成和已取消实例，点击实例进入任务详情；“选择”支持多选取消待执行任务。暂停仅停止后续补齐，已生成任务和完成记录保留；恢复后继续补齐未来30天。“编辑规则”先展示变更预览，仅对后续新生成的任务生效，已生成任务和手动调整保持不变。详情菜单中的“结束批次”停止补齐并保留生成记录，已结束批次不能直接恢复。新建批量任务使用独立草稿，不覆盖普通新建任务的草稿。

批量任务可设置可选的“优先时间点”：新建时进入“多次任务”，已有批次进入“编辑规则”。生成时在原规则选定的当天先尝试该精确时间；有冲突时，在允许时段及实际可用时间内选择最接近的空位，同距离取较早时间。优先点必须能在允许时段内完整放下每次任务；清空后恢复原安排方式。优先时间不改变重复日期规则，不覆盖手动调整，修改仅影响后续新生成任务。

本文说明现有使用入口；当前版本的待核验事项见 [项目待办](../BACKLOG.md)，具体设备覆盖见 [验证索引](../VERIFICATION.md)。

## 项目目录与跟进

打开「项目」可逐层浏览分类。项目设置可调整所属分类、重要性和目标完成日期。项目内可以继续建分类、新建任务或从独立任务中移入已有任务。原有未归类项目收在「未分类」。项目和任务的「固定到跟进」会把同一项加入平铺视图，取消固定仍保留其原有位置。

在项目里点「挑任务」，跨分类勾选后查看总耗时与未估时数量，再一次加入时间表的待安排区。单项也可左滑，或长按条目从菜单选择「加入待安排」。待安排跨周保留。长按拖入时间表后，选中时间块可打开所属项目，再返回原时间表。项目任务详情可取消未锁定的时段，将任务放回待安排。项目进度显示完成数量；设置目标日期后可查看预计延期与实际完成偏差。「完成项目」需要手动确认。

「用 AI 拆解」打开带项目上下文的可编辑草稿。配置并发送后，助手可在一次变更审核中创建多个分类和任务，排程仍由用户挑选。
