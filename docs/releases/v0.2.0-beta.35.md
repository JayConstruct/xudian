# v0.2.0-beta.35

在模块商店安装「想法」1.1.1 后，可从「更多」随手记录，按日期、关键词或收藏回看。长按一条想法可编辑、删除或从原文创建任务和项目，点「已创建」可再次打开对应记录。输入法完成键支持连续记录，保存失败时可以保留正文并重试。

课表更新了课程管理与单次课时编辑。今日、AI 和界面示例同步更新，设置与模块管理沿用统一的日期选择、分段切换、弹窗和返回交互。「紧凑界面示例」退出分发。

已有用户请先更新 Android 测试版，再在模块商店更新所需模块。[想法模块](https://github.com/JayConstruct/xudian/releases/tag/modules-ideas-1.1.1) · [本轮其他模块](https://github.com/JayConstruct/xudian/releases/tag/modules-20261124-workspace)
