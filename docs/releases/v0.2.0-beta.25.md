## 本次更新

- 任务规划拖动和当日列表拖放统一为5分钟增量；手动编辑仍支持任意分钟。拖到课程、固定或已完成任务上时，显示占用冲突。
- 时间轴支持双指缩放并保存倍率，修复近距离起手、额外手指干扰和中途离开页面的手势状态。
- 新增“视图与显示 → 详情显示”。课程卡片、当日列表和选中详情可控制地点／老师，两个预览分别跟随各自设置。
- 课表上下滚动不再拉开缝隙，保留惯性滚动及工具栏折叠／展开。
- 拾光导入支持去掉校区保留教室，或不导入地点；保留原始采集结果，可恢复。取消实际变更后返回可继续同一草稿，校区识别保留教室编号及 `-101` 等负号。
- 修复横向滚动或取消拖动后，详情菜单偶尔无法打开的问题。
- 公开 APK 统一使用 `xudian-v0.2.0-beta.25-ABI-release.apk`，文件名包含应用名称、版本和 ABI；本地导出保留中文名称。旧更新器也能识别公开文件名。
- 一键更新在测试前刷新模块包，并把模块源码纳入检查指纹，避免误测旧包。

## 安装与模块更新

此版本继续使用既有固定签名。按设备 ABI 选择安装包；已有安装应覆盖更新并保留数据，签名不匹配时不要卸载或清数据。

任务规划 **1.13.2** 要求本版本宿主 API **1.47.0**；拾光导入更新为 **1.8.2**。APK 更新不会自动替换已安装的独立模块，请在模块商店审核更新，或导入对应 `.xmodule` 包。两模块的不可变发布标签为 `modules-20261104-planner-display-import`。

beta.24 发布核验发现 GitHub 清洗中文附件名，导致三个附件名称与摘要清单不一致；安装包内容及固定签名通过核验。本版修正公开命名与摘要清单，beta.24 的既有附件和标签保留。

## 验证范围

相关本地回归、Android x86_64 模拟器页面操作、返回／重开和冷启动验收后发布；完整 Flutter 回归及三 ABI 构建由 CI 执行。拾光地点与返回流程使用本地教务夹具验证，未代替真实学校账号登录验收。ARM 真机与 Windows 运行情况未在本轮验证。
