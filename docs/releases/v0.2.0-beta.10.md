# 序点 0.2.0-beta.10

- 任务规划缓存内的日期浏览改为原生本地滚动，不再每滑动一次就查询、刷新整个页面；临近数据边缘时后台补充日期，无缓存的日期列显示局部加载及重试入口。
- 日期列循环复用，缓存有界，不因长时间浏览持续增加内存；后台旧回复不能覆盖新浏览位置、顶栏或输入草稿。
- 修复表头与正文同步时提前启动吸附动画、反过来打断手指拖动的问题。被动一侧只跟随，松手后由主动一侧吸附；按住暂停、继续移动、反向拖动和接管惯性滚动不再被另一侧抢占。
- 保留紧凑布局、连续日期、待安排浮层、原生调整开关及任务拖放审核；浏览位置延迟合并保存，切页或进入后台时刷新保存。

动态加载需要任务规划模块1.6.1及宿主API1.36.0。请先更新App，再在模块商店手动更新任务规划；本次不新增模块权限、不迁移任务或课程数据。

测试版延续beta.7起的固定Android发布签名。更新前请备份数据；更早版本或本机开发签名的安装可能无法直接覆盖，不要为更新而卸载应用或清除已有数据。已完成Android模拟器实际按住、停手及反向拖动的位置跟随验收，未将其宣称为真机帧率测试；ARM真机与Windows运行效果尚未验证。
