# 序点 0.2.0-beta.15

- 在任务规划中点击日期表头，可打开当天的任务清单。顶部显示待安排任务，下方按时间排序；任务块大小一致，隐藏空闲时段，几分钟的小任务也能清楚显示。
- 任务块左侧分两行显示开始、结束时间，右侧显示任务名与时长；跨日任务保留日期提示，来自课表的只读课程保留斜纹与锁定标识。
- 支持长按将待安排任务拖入清单，再调整开始时间和分钟数。拖动先生成待确认预览，确认后沿用现有时间校验与保存流程；时间重叠会提示冲突，并可选择后续空档，其他任务保持原时间。
- 当日窗口增加260毫秒的淡入、轻微上移和缩放，关闭采用180毫秒退场；支持快速返回和系统“减少动画”设置。优化返回键、待安排折叠按钮与弹窗的无障碍访问。
- 本次无需升级独立模块。

已在 Android 模拟器验证弹窗、拖入预览、开始时间与3分钟时长编辑、取消恢复、返回退出及重新打开，保留原有任务数据；保存与刷新通过独立数据库的真实服务集成测试验证。测试版沿用固定 Android 发布签名；更新前请备份数据，历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。ARM真机与Windows运行尚未验收。
