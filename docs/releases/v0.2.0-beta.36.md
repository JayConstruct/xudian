# v0.2.0-beta.36

想法按记录时间从早到晚排列，最新一条显示在底部。长按想法可直接标记完成、复制完整正文，或沿用原文创建任务和项目。长按菜单的内边距加大、边框调淡，底部输入框留出更多空间。编辑后点一次「保存」即可返回。切换「全部」与「收藏」时加入内容过渡动画，在「收藏」中搜索只显示已收藏的想法。

任务规划调整了时间表中的空闲时段显示和日期导航，可在时间轴顶栏切换快速调整。设置中的「布局与导航」支持搜索入口、拖动排序、跨分区移动，以及移除和撤销。编排完成后点「保存布局」即可应用。

已有用户请先更新 Android 测试版，再到模块商店更新「想法」1.3.0 和「任务规划」1.17.2。[下载本轮模块](https://github.com/JayConstruct/xudian/releases/tag/modules-20261127-ideas-planner)
