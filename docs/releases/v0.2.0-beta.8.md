# 序点 0.2.0-beta.8

- 任务规划的任务块统一为圆角矩形，移除左侧线条，使选中边框切换更连贯。
- 作息设置改为表格，优化滚动和编辑时的闪烁。统一设置每节时长后，修改开始时间会自动计算结束时间，手动修改的结束时间会保留。
- 教务导入预览的确认和取消操作固定在屏幕下方，确认后不再重复弹出数据变更审核。导入完成后可直接关闭导入界面并打开主课表。
- 模块页面按前进、返回分别使用入场和出场动画，与 App 页面保持一致。
- 课表上滑时先收缩顶栏，再滚动表格；底栏与展开按钮使用独立动画。
- 模块下载遇到临时断网或代理掉线时增加有限重试，并提供明确的错误与重试状态。

作息表格需要大学课表模块 1.16.2，导入流程更新需要拾光教务导入模块 1.7.2；请先更新 App，再在模块商店中手动更新模块。

测试版与 beta.7 共用固定 Android 发布签名。更新前请备份数据；更早版本或本机开发签名的安装可能无法直接覆盖，不要为更新而清除已有数据。
