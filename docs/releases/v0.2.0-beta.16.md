# 序点 0.2.0-beta.16

- 当日任务清单改为全屏视图，覆盖工具栏与底部导航，保留现有配色、只读斜纹和开关动画。关闭或返回后回到原时间轴位置。
- 任务行默认高度缩至48dp，开始与结束时间合并为任务名下方的一行；几分钟的小任务与长任务保持等高，大字体时自适应增高。
- 长按拖动、悬停时，已安排任务始终保持8dp间距，用细线提示插入位置，避免任务被撑开后跳动。
- 修正全屏视图中的时间、时长选择器层级与Android返回处理。返回键先关闭编辑对话框，再关闭当日任务视图；服务校验期间也能返回，后台保留的页面不拦截其他页面的返回。全屏时隔离被覆盖内容的无障碍焦点。
- 本次无需升级独立模块。

已在Android模拟器验证全屏显示、长按与悬停位置稳定、拖入预览、开始时间与3分钟时长编辑、取消恢复、Android返回及重新打开；保留原有任务数据。保存与刷新通过独立数据库的真实服务集成测试验证。测试版沿用固定Android发布签名；更新前请备份数据，历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。ARM真机与Windows运行尚未验收。
