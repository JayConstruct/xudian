# 序点 0.2.0-beta.7

- Android 测试版和正式版发布统一使用固定签名，后续版本沿用同一密钥，避免每次 CI 生成临时签名导致无法覆盖更新。
- 签名在独立任务中完成，编译和测试不接触发布私钥；逐个验证 ARMv7、ARM64 和 x86_64 APK 的签名及固定证书指纹，缺少配置或校验失败时停止发布。
- 本次仅更新客户端版本与发布流程，业务功能和独立模块版本保持 beta.6 的内容。

**首次切换签名：beta.6 及更早测试版使用过临时签名，可能无法直接覆盖安装本版。请先完整备份并确认数据可恢复，再安排重新安装或迁移；新签名不会自动迁移旧安装的数据。** 后续使用本次固定签名发布的版本可按 Android 版本要求覆盖更新。

公开证书 SHA-256 指纹（不是私钥）：

```text
cdb8ef381555450ad2e6f04dafa4a52635f84fa4fc22fdb92ef776ccb6abc4fd
```

多数 Android 手机选择 `app-arm64-v8a-release.apk`；旧 ARMv7 设备选择 `app-armeabi-v7a-release.apk`，x86_64 模拟器选择 `app-x86_64-release.apk`。下载后可使用随包发布的 `SHA256SUMS` 核对文件摘要。

这是测试版，不进入默认正式更新通道；开启应用内“测试通道”可检查此版本。ARM 真机与 Windows 的运行验证范围见仓库验收记录。
