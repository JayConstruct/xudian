# 序点 v0.2.0-beta.29

- 任务支持项目与目录，可从项目内查看待安排任务、已计划任务和活动，并通过行菜单执行常用操作。
- AI 助手可生成项目拆解草案，经确认后在当前项目中创建目录和任务。
- 设置首页按外观、布局、应用数据和支持分组，保留现有设置与模块管理入口。
- 更新任务规划和大学课表模块，并整理宿主组件、测试和开发文档。

本版为 Android 测试版，包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 三种 APK。应用内检查此版本需启用测试通道。

可同时更新任务 `1.11.1`、AI 助手 `1.6.2`、任务规划 `1.16.0` 和大学课表 `1.16.6`。任务 `1.11.1` 需要宿主 API `1.54.0`。已有安装请先更新 App，再通过模块商店更新已安装模块。[模块包](https://github.com/JayConstruct/xudian/releases/tag/modules-20261119-project-directories)
