# 序点 0.2.0-beta.13

- 设置首页新增“更新设置”，提供“启动时检查更新”开关，默认关闭，选择保存在本机。
- 开启后从下次冷启动起，在首帧后异步并行检查 App 和已安装模块，包含已停用模块；切换页面、修改设置和返回前台不会重复触发。
- App 检查沿用已选择的正式／测试通道；模块沿用商店目录源，只查询已安装模块的版本索引，筛选兼容当前宿主的正式版本。
- 检查不阻塞启动，两类检查分别限时 30 秒，网络失败静默处理；单项失败不影响另一项检查结果。发现更新时提供“查看”提醒，更新设置页保留本次检查结果与手动检查入口。
- 检查只读取版本信息。App 下载仍打开发布页，模块下载和安装仍在模块商店审核确认。本次更新无需升级独立模块。

已完成 Android 模拟器的开关保存、开启后的冷启动检查和关闭后跳过检查验收。测试版沿用固定 Android 发布签名；更新前请备份数据，历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。ARM 真机和 Windows 运行尚未验收。
