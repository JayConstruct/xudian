# 序点 0.2.0-beta.11

- 日程默认突出正在或下一节课程，支持展开全部课程与收起；课程较多时，首屏也能看到待办正文。任务日期显示更紧凑，保留精确截止时刻、跨日时间与时区，并明确标注逾期。
- 修复在日程只修改任务标题或优先级时，意外清除精确截止时间的问题；没有变化的字段不再重复提交。
- 新建任务面板降低初始高度、缩小表单间距，保留描述、截止时间和详细规则的按需展开，以及独立保存按钮与输入草稿。
- 规划拖动期间延后普通后台刷新，避免跨分钟刷新打断手势；边缘自动滚动改为帧同步并按实际经过时间计算位移。补齐减少动画和折叠顶栏的焦点保护，保留连续日期、缓存与联动滚动。
- 修复取消 AI 撤销审核后入口消失的问题；已提交工具操作保留回执，后续失败或取消明确展示部分完成。工具授权失效时显式重新申请，不自动重放写入；拒绝保存回执时停止后续工具并提示当前会话保留的限制。
- 首次合并课表时，学期、时区或作息基准不一致将要求明确选择并解释影响，不再静默套用。显式日期的混合时区课程按实际时间排序，覆盖夏令时边界。

请先更新 App，再在模块商店手动更新：日程1.8.1、AI助手1.5.1、大学课表1.16.3、任务规划1.6.2、拾光教务导入兼容1.7.3。日程和AI也已纳入当前App可信预装资源；已有安装不会因APK覆盖而自动升级模块。本次不新增模块权限，不清除或迁移任务与课程数据。

测试版延续既有固定Android发布签名。更新前请备份数据；历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。已完成Android模拟器页面验收与相关回归，未将其宣称为ARM真机帧率或Windows运行验收。
