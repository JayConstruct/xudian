# 序点 0.2.0-beta.9

- 任务规划改为紧凑单行顶栏、待安排任务横条与浮层、单行日期表头，为时间表腾出更多高度。
- 默认显示昨天、今天和明天，横向连续浏览过去与未来，支持周末、跨月与跨年；离开今天后显示“回到今天”，不再挤动表格。
- 切换页面或重启后重新打开任务规划，保留浏览日期；数据窗口更新、任务放大返回与时间轴缩放保持浏览位置。
- 课表折叠顶栏后向下拖动，先将表格滚回顶部，再展开顶栏，最后产生下拉间隙。
- 课程方块缩小内边距、扩大文字显示区域，标题可显示更多行。

连续日期与紧凑布局需要任务规划模块1.6.0及宿主API1.35.0。请先更新App，再在模块商店手动更新任务规划；本次不新增模块权限、不迁移任务或课程数据。

测试版与beta.7、beta.8共用固定Android发布签名。更新前请备份数据；更早版本或本机开发签名的安装可能无法直接覆盖，不要为更新而卸载应用或清除已有数据。已完成Android模拟器验收，ARM真机与Windows运行效果尚未验证。
