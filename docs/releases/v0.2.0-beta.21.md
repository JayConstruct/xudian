# 序点 0.2.0-beta.21

- 任务规划新增“批量任务”管理入口，支持按批次搜索筛选、查看生成实例及完成／取消记录，暂停恢复、结束批次、规则变更预览和多选取消。
- 批量任务新增可选“优先时间点”，支持精确分钟；有冲突时在当天允许时段内就近安排，清空后恢复原安排方式。新建草稿与模板保存该设置，修改仅影响后续新生成任务，保留已有安排和手动调整。
- 批次内处理单次任务后返回原批次，保留筛选和位置；改进长标题、窄屏、大字号和无障碍呈现。
- 扩展宿主通用卡片、徽标、搜索、页签、固定底栏和紧凑详情顶栏；修复脚本执行器关闭后无法恢复的问题，后续操作可重新初始化，失败操作不自动重放。
- 请先升级 App，再更新任务规划模块至1.12.0；该模块需要宿主API1.45。已有数据保留，不自动升级已安装模块。需要回退旧规划模块时，应使用升级前的数据快照；旧模块不能完整识别新增优先时间配置和批量取消历史。

本次为测试版，沿用固定 Android 发布签名。设备覆盖与具体测试见发布验收记录；ARM真机和Windows原生运行不在本轮实机范围。
