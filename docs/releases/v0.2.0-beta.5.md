本版改进任务规划表格、拖动操作和确认流程，新增可记忆的显示时段设置。

- 表格右侧时钟入口提供自动按任务、手动设置上下限和显示全天。自动模式按当前日期范围内的任务及课程确定时段，前后至少留一小时并对齐整点；无安排时显示08:00–22:00。手动范围外的安排仍可查看，设置重启后保留。
- 改进待安排折叠、任务卡片到真实占用带的拖动过渡、短任务放大、起止刻度、重叠任务选择及课程地点和教师显示。
- 增加默认关闭的快速调整；单个移动与时长调整可直接保存并撤销，交换、超截止和其他需要确认的操作继续审核。保存期间展示落点，失败时恢复并支持重试。
- 优化滚动时的文字绘制、几何缓存及页面数据读取；改进顶部操作、面板返回和键盘遮挡处理。

宿主API为1.29.0。同步发布任务规划1.4.8、大学课表1.15.1。已有用户先更新APK，再到模块商店确认模块更新；覆盖安装APK不会自动升级已安装的独立模块。

Android提供ARM64、ARMv7及x86_64 APK，普通手机通常选择app-arm64-v8a-release.apk。SHA256SUMS与SOURCE_COMMIT用于核对文件及源码。

这是测试版，使用CI开发签名。签名不匹配时保留现有安装并先备份数据，不卸载或清除数据。正式版本检查会过滤测试版。已完成Android模拟器验收；ARM真机帧率与Windows原生构建未验证。
