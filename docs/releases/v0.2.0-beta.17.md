# 序点 0.2.0-beta.17

- 任务规划用右侧彩色细线标识未完成任务，完成后收拢为深色白勾角标，约280ms可逆过渡；重新打开任务时恢复细线。标识不挤占标题与时间，减少动态效果时直接切换。
- 在规划界面选中任务后可直接完成或重新打开。记录完成时间，并提供“完成记录与复盘”页面，便于回看完成的任务。
- 日程、课表及任务规划的普通时间展示不再附带时区，必要的时区配置仍可在设置中查看和调整。
- 新建、勾选完成等已明确选择的单项操作不再重复弹出“确认实际数据变更”；删除、批量变更和需要额外风险确认的操作仍保留审核。
- 请先升级 App，再更新模块：任务规划1.7.4、任务核心1.6.0、日程1.9.0、大学课表1.16.4。新的规划状态标识需要宿主 API 1.40，旧 App 无法使用。

已完成 Android 模拟器页面验收及相关回归，保留原有任务和模块数据；模拟器结果不代表 ARM 真机或 Windows 运行验收。测试版沿用固定 Android 发布签名；更新前请备份数据，历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。ARM 真机与 Windows 运行尚未验收。
