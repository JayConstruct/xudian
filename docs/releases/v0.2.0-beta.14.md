# 序点 0.2.0-beta.14

- 任务规划中，从课表导入的课程标题支持自动换行；并排课程也能利用可用高度显示更多文字。
- 任务块更贴近时间表网格，减少左右留白，扩大标题的显示区域；选中任务保持原有尺寸。
- 修复连续的30分钟子任务被误判为重叠、组合后标题消失的问题。实际重叠的短任务在空间足够时分别显示标题，拥挤或过短时保留聚合入口。
- 本次调整不改变任务起止时间，无需升级独立模块。

已完成 Android 模拟器的任务规划页面验收，覆盖课程换行、窄列布局及短任务标题回归。测试版沿用固定 Android 发布签名；更新前请备份数据，历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。ARM 真机和 Windows 运行尚未验收。
