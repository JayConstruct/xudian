# 任务新建、批量规则与持续规划

- 重新设计新建任务面板，区分单次和批量；描述按需展开，规则、模板及安排预览各有独立子页面，返回后保留输入草稿。
- 模板采用无图标文字列表，支持内置模板、搜索、个人模板保存与删除。套用模板后仍可修改配置。
- 批量任务默认支持相邻两次间隔4～6天，按当天向后规划30个自然日。可选择允许星期、允许时段与优先级；每日安排和间隔安排二选一。
- 确认前展示具体日期、未安排原因和实际数据变更，计入任务、课程及手动占用。30天课程占用按课表服务限制分段读取，保留跨时区边界检查。
- 预览与生成后的任务均支持手动调整时间，选择“仅本次”或“本次及以后”，并检查相邻间隔及冲突；后续已有手动调整不会被静默覆盖。
- 确认批量生成后，在启动、恢复前台及前台运行时补齐当天往后的30天，保留已有任务和手动安排，不重复生成。关闭应用期间不承诺后台常驻；再次打开时继续补齐。撤销批量创建同时撤销持续规划规则。
- 任务块选中时保持文字与UI尺寸，点击其他区域取消选中；底部选中浮窗与导航底栏使用统一样式。课程块移除图标，将空间留给文字。

请先更新App，再在模块商店手动更新任务规划至1.7.1。该模块要求宿主API 1.37.0，并新增“执行已配置的自动化流程”权限，用于已确认批量任务的持续补齐；更新时会显示完整权限审核。覆盖APK不会自动升级已有模块。

测试版沿用固定Android发布签名。更新前请备份数据；历史临时签名或本机开发签名安装可能无法直接覆盖，不要为更新而卸载应用或清除数据。已完成Android模拟器的生成、手动调时、选中、撤销及重启验收；ARM真机和Windows运行尚未验收。
