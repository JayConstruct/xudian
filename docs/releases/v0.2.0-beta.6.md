# 序点 0.2.0-beta.6

- 课表与任务规划使用柔和彩色卡片。颜色按稳定身份自动计算，超出预设色数继续扩展；同课程在两页保持同色，任务从待安排移到时间网格后保持颜色。
- 课程编辑支持留空自动配色或明确指定颜色，保留来源配色；课程占用以纹理区分，改进深浅主题的标题可读性。
- 任务规划使用分级菜单管理视图、显示时段和筛选，支持时间轴缩放，保留候选区域的浏览位置。
- AI 助手采用紧凑对话布局和统一设置入口，支持模型连接与工作模式设置。
- 设置新增“导出所有配置”，默认不包含密钥，可选择保存配置 JSON。

本次模块更新：AI 助手 1.5.0、任务规划 1.5.2、大学课表 1.16.0。既有安装的模块需在商店中确认更新。

这是测试版，沿用项目的 CI 开发签名。当前源码已在 Android 模拟器保留数据覆盖安装验收；公开 APK 由发布工作流构建，真机与 Windows 平台验证范围见仓库验收记录。
