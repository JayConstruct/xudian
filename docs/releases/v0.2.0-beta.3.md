本版改进启动与日程加载、模块商店和安装审核，并修复跨模块导航、错误提示与系统时区处理。

- 启动恢复复用本轮已校验模块包，提前读取保存的入口布局；前台操作优先于排队中的日期预取。
- 日期缓存按依赖同步失效，保留草稿、事务回滚和副作用保护；50 项精确计划的时间转换桥接从 100 次降至 1 次，显示结果保持一致。
- 模块商店增加紧凑布局、状态/分类筛选和下载进度；安装与数据变更审核展示用途、权限和实际增改删内容，长文本可滚动复制。
- 修复导入后仍停留在覆盖页面的问题，错误提示只显示可读正文；新建课表默认读取系统时区，已有时区设置保持。
- 增加显示诊断与本地性能计时；完善小屏、大字体和弹窗布局。

宿主 API 更新至 1.23.0。预装日程为 1.8.0；模块商店同步提供课表 1.14.0 与拾光 1.6.0。已有用户安装新版 APK 后，请在模块管理/商店单独确认模块升级；更新 APK 不会自动替换已有模块。

Android 提供 ARM64、ARMv7 和 x86_64 三种 APK；通常手机选择 `app-arm64-v8a-release.apk`。`SHA256SUMS` 和 `SOURCE_COMMIT` 用于核对文件及源码。

这是测试版，沿用 CI 开发签名；签名不匹配时不要通过卸载现有应用强行覆盖，先备份数据。App 的正式版本检查会过滤测试版。Windows 未发布安装包，真机启动耗时和帧率仍待实测；上述调用次数减少不代表相同比例的实际提速。
