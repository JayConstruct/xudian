本版加入任务规划图形时间表、快速新增、拖动安排和整体撤销，并改进模块加载与课表导入流程。

- 规划页按五天显示候选任务、已安排任务及只读课程占用；支持横纵滚动、长按移动、交换、拉伸时长和精确时间编辑。
- 快速新增仅要求任务名称，可选描述、截止和具体时间；手机使用底部面板，宽屏使用居中弹窗。
- 候选任务分页并保留跨页选择；图形区按可见日期和时段构建，减少大批任务的挂载开销。
- 安排和撤销检查任务版本、固定状态、截止及新增占用；跨午夜与夏令时移动保持实际持续时间。
- 包含此前提交的模块加载、导航一致性及学校导入改进。

宿主 API 为 1.25.0。预装任务模块更新至 1.5.1；商店提供任务规划 1.3.0、任务 1.5.1、大学课表 1.15.0 与拾光 1.7.0。已有安装请先更新 APK，再到模块商店确认模块升级；APK 更新不会自动替换已安装模块。

Android 提供 ARM64、ARMv7 和 x86_64 APK，通常手机选择 app-arm64-v8a-release.apk；SHA256SUMS 与 SOURCE_COMMIT 用于核对文件与源码。

这是测试版，使用 CI 开发签名。签名不匹配时应保留现有安装并先备份数据；正式版本检查会过滤测试版。插入顺延、有限生成器、完整草稿恢复及外部可写来源尚未完成；真机帧率和 Windows 原生构建未验证。
