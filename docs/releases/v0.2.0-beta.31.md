# 序点 v0.2.0-beta.31

- 设置新增搜索和入口目录，可定位到具体选项。布局设置提供入口安排和导航外观预览。
- 设置、模块商店、模块管理与模块页面共享更多界面组件。商店跟随全局选用的 UI 包。
- 大学课表更新课程管理、周选择与课表设置。拾光教务导入统一学校及通用系统入口、预览和冲突处理页面。
- AI 助手的模型连接等选项可从设置搜索找到。

本版为 Android 测试版，提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 三种 APK。应用内检查此版本需启用测试通道。

同步发布 AI 助手 `1.7.1`、大学课表 `1.17.2` 和拾光教务导入 `1.9.1`。后两项需要宿主 API `1.55.0`。已有安装请先更新 App，再通过模块商店更新已安装模块。[模块包](https://github.com/JayConstruct/xudian/releases/tag/modules-20261120-unified-settings)
