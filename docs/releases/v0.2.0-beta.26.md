## 本次更新

- 模块页面新增属性动画、按钮按压反馈和横向滑出操作。模块可配置位移、透明度、缩放、时长、曲线和操作事件；兼容宿主上修改这些配置只需更新模块。
- 动画插值和手势跟踪在 Flutter 本地执行，不逐帧调用 JavaScript；支持减少动态效果、页面失活取消、局部动画预算及复杂内容菜单回退。
- 任务与规划模块通过记录契约声明自己的字段、集合和历史保留规则；宿主继续校验实际写入、占用和撤销。强化页面调用隔离，防止旧弹窗返回影响新调用。
- 优化模块详情与审核加载、集合查询及渲染职责划分；补充独立模块升级、冷启动与返回重开回归。

## 安装与模块更新

此版本宿主 API 为 **1.50.0**，继续使用既有公开固定签名。按设备 ABI 选择 APK，覆盖更新并保留数据；签名不匹配时不要卸载或清数据。

同步提供任务 **1.7.0**、任务规划 **1.15.1**、UI 示例 **1.5.0**。APK 更新不会自动替换已安装的独立模块，请先更新宿主，再在模块商店审核更新或导入对应包。模块不可变发布标签为 `modules-20261116-ui-runtime`。

## 验证范围

发布前执行相关本地检查和 Android x86_64 模拟器验收，包含滑动操作、弹窗取消／返回／重开、规划编辑取消、商店离线恢复及进程冷启动；完整 Flutter 回归及三 ABI 构建由 CI 执行。独立模块升级已核对 APK 摘要保持不变。

本版为 Beta。尚未测量 ARM 真机帧率和峰值内存，未完成 Windows 与 TalkBack 专项验收；不承诺性能无损。拖动排序、通用缩放手势及组合时间轴属于后续设计，不在本版新增能力中。
