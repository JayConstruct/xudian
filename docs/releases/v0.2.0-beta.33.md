# v0.2.0-beta.33

任务规划现在会根据屏幕可见的日期、任务和当前视口调整时间表上下限。横向查看相邻日期时可以看到早晚任务。要查看空白时段，在顶部或底部继续拖动 72 dp 即可展开全天。拖动中有进度提示，达到阈值时提供触感反馈。展开状态持续到关闭 App。

可以把任务安排到过去。安排弹窗会显示日期、时段和相关提示，确认一次即可保存。自动安排和规则预览也只需确认一次。

先更新 Android 测试版，再在模块商店更新任务规划至 1.17.1。[任务规划模块](https://github.com/JayConstruct/xudian/releases/tag/modules-20261124-planner-smart-hours)
