# 设置层级

2026-10-08：当前生产宿主的设置采用分类首页，具体选项进入二级页。手机与电脑使用同一分类，桌面内容宽度限制为 760；布局编辑器保留宽屏双栏。

```text
设置
├─ 外观与交互
│  ├─ 外观主题 → 跟随系统 / 浅色 / 深色
│  ├─ 界面风格 → 全局风格 / 模块专属界面 / 保存与恢复
│  ├─ 减少动画
│  └─ 触感反馈
├─ 布局与导航 → 入口与页面布局编辑器
├─ 模块与连接
│  ├─ 模块管理与恢复
│  ├─ 模块商店
│  ├─ 模块提供的设置（settingsSections 贡献）
│  └─ 模块专属设置（挂载到设置的内容页面）
├─ 辅助工具 → 界面标注模式
├─ 关于序点 → 应用与本机数据说明 / 项目地址 / 模块仓库
└─ 常用入口（按当前屏幕布局的顺序展示）
```

首页分为“个性化”“功能与支持”和可选的“常用入口”。分类行统一使用图标、标题、简短摘要与右箭头。外观行显示当前主题；辅助工具行显示标注状态。主题与交互偏好读取失败时，分类仍可访问，外观页提供重试。

外观页的主题、动效和触感修改自动保存，保存期间禁用这些控件，失败保留已应用设置并提示重试。界面风格与布局继续使用显式保存的草稿；说明文字区分自动保存、预览与保存后应用。界面风格与恢复页面使用内置界面。

“布局与导航”直接打开编辑器，避免只有一个选项的中间页。从设置进入时，根据 820px 分界默认选择手机或电脑配置，仍可手动切换。

模块的 `settingsSections` 贡献移到“模块与连接”下单独成组。挂载到设置的普通入口保留在首页常用入口；内容页面仅在模块分类显示一个入口，打开后完整显示，不再在首页重复内嵌固定高度页面。两种入口都遵循当前布局顺序，并把挂载上下文传给 `UiPageHost`。

关于页保留地址打开、复制、打开模块商店等操作；与“模块与连接”共用当前配置的模块目录。关闭业务模块后，设置分类及模块管理恢复路径仍然可用。

入口为 `client/lib/core/module_host/host_settings_page.dart`。`features/settings/settings_page.dart` 为旧模块架构的兼容页面，不是生产壳层的设置入口。

验证覆盖设置分类的进入与返回、主题与交互偏好持久化、辅助工具状态摘要、320px 大字号、宽屏深色、当前设备布局默认选择、入口排序、内容页面只按需构建及上下文传递。既有宿主恢复、模块设置贡献、界面包、模块商店与课表壳层回归随新层级调整。
