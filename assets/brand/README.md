# 序点品牌资源

名称：**序点**。含义是把待办事项变成清晰、可执行的顺序节点。英文内部代称为 **Xudian**；正式商标与应用商店名称发布前仍需检索确认。

`icon.svg` 是图标母版：深靛色代表专注，青绿色节点代表推进，最后的勾代表完成。图形无文字，以适应 Android 启动器和 Windows 任务栏的小尺寸显示。

![序点图标预览](icon_preview.png)

`generate_icons.py` 从母版导出 Android 各密度 PNG、Windows 多尺寸 ICO 和预览图。修改图标后运行 `python3 assets/brand/generate_icons.py`，再重新构建应用。
